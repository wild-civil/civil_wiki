# 稳定性与根轨迹

> 一句话：**稳定性只看闭环极点在哪**——全在左半平面就稳。Routh 判据不解根就能判；根轨迹则把"增益变大时极点往哪跑"画成一张图。

## 一、稳定性的定义

对连续时间 LTI 系统：

| 极点位置 | 稳定性 | 响应 |
|---|---|---|
| 全在左半平面（LHP） | **渐近稳定** | 扰动后回到平衡 |
| 虚轴上有一对单极点，其余在 LHP | **临界稳定** | 等幅振荡 |
| 任一极点在右半平面（RHP） | **不稳定** | 发散 |
| 虚轴上有重极点 | **不稳定** | 发散（$t$ 乘振荡） |

> 记住：**稳定性由极点决定，与零点无关**。零点只改变响应形状（超调、反调），不改变"稳不稳"。

## 二、Routh-Hurwitz 判据：不解根也能判稳

### 2.1 特征方程

闭环传递函数的分母 = 0：

$$a_n s^n+a_{n-1}s^{n-1}+\cdots+a_1s+a_0=0,\qquad a_n>0$$

### 2.2 必要条件（先快速筛）

**所有系数都存在且同号（都为正）**。

> ⚠️ 这是**必要**条件，不是充分条件。系数全正也可能不稳定（例如 $s^3+s^2+s+6=0$）。

### 2.3 Routh 表

把系数交替排成两行，再逐行算下去：

| | 第 1 列 | 第 2 列 | 第 3 列 |
|---|---|---|---|
| $s^n$ | $a_n$ | $a_{n-2}$ | $a_{n-4}$ |
| $s^{n-1}$ | $a_{n-1}$ | $a_{n-3}$ | $a_{n-5}$ |
| $s^{n-2}$ | $b_1$ | $b_2$ | … |
| $\vdots$ | $\vdots$ | $\vdots$ | |
| $s^0$ | $a_0$ | | |

其中：

$$b_1=\frac{a_{n-1}a_{n-2}-a_n a_{n-3}}{a_{n-1}},\qquad b_2=\frac{a_{n-1}a_{n-4}-a_n a_{n-5}}{a_{n-1}}$$

**判据**：Routh 表**第一列变号的次数 = 右半平面根的个数**。第一列全为正 → 全部根在 LHP → 稳定。

### 2.4 例 1：稳定的三阶系统

$$s^3+4s^2+5s+2=0$$

| | 第 1 列 | 第 2 列 |
|---|---|---|
| $s^3$ | 1 | 5 |
| $s^2$ | 4 | 2 |
| $s^1$ | $(4\times5-1\times2)/4=4.5$ | 0 |
| $s^0$ | 2 | |

第一列：$1,4,4.5,2$，全正，**0 次变号 → 稳定**。（实际根：$-1,-1,-2$。）

### 2.5 例 2：不稳定的三阶系统

$$s^3+s^2+2s+8=0$$

| | 第 1 列 | 第 2 列 |
|---|---|---|
| $s^3$ | 1 | 2 |
| $s^2$ | 1 | 8 |
| $s^1$ | $(1\times2-1\times8)/1=-6$ | 0 |
| $s^0$ | 8 | |

第一列：$1,1,-6,8$，符号 $+,-$ 变一次、$- ,+$ 又变一次 → **2 次变号 → 2 个 RHP 根 → 不稳定**。

### 2.6 例 3：求增益范围（最常用）

环路 $G(s)=\dfrac{K}{s(s+1)(s+2)}$，闭环特征方程：

$$s(s+1)(s+2)+K=0\;\Longrightarrow\;s^3+3s^2+2s+K=0$$

| | 第 1 列 | 第 2 列 |
|---|---|---|
| $s^3$ | 1 | 2 |
| $s^2$ | 3 | $K$ |
| $s^1$ | $(6-K)/3$ | 0 |
| $s^0$ | $K$ | |

稳定条件：

$$K>0,\qquad \frac{6-K}{3}>0\;\Longrightarrow\;0<K<6$$

- $0<K<6$：稳定；
- $K=6$：临界（虚轴上有根）；
- $K>6$：不稳定。

> 这个 $K=6$ 的结论，下面根轨迹会从几何上再看到一次。

### 2.7 两个特殊情况

| 情况 | 现象 | 处理 |
|---|---|---|
| 第一列出现 0，其余不为 0 | 不能直接判 | 用 $\varepsilon>0$ 代替 0，令 $\varepsilon\to0$；或乘 $(s+a)$（$a>0$）再列 |
| 整行全为 0 | 有对称根（常为 $\pm j\omega$） | 用上一行构造**辅助多项式**，对 $s$ 求导，用导数系数替换该行 |

> 整行为 0 往往意味着"临界稳定"——根正好落在虚轴上。

## 三、根轨迹：极点随增益怎么跑

### 3.1 定义

闭环特征方程：

$$1+K G(s)H(s)=0$$

当 $K$ 从 $0$ 变到 $\infty$，闭环极点在 $s$ 平面上画出的轨迹，就是**根轨迹**。

等价条件：

$$\vert G H\vert=\frac{1}{K},\qquad \angle G H=(2k+1)180^\circ$$

- **幅值条件**定 $K$；
- **相角条件**定轨迹形状（与 $K$ 无关）。

### 3.2 七条规则

| # | 规则 |
|---|---|
| 1 | 起点：$K=0$ 时在**开环极点**；终点：$K\to\infty$ 时在**开环零点**，没有零点就去无穷远 |
| 2 | 分支数 = 开环极点数 $n$；其中 $n-m$ 条奔向无穷远（$m$ 为零点数） |
| 3 | 实轴上的根轨迹：某点**右侧**的极点 + 零点数为**奇数**时，该段在轨迹上 |
| 4 | 无穷远渐近线：角度 $\dfrac{(2k+1)180^\circ}{n-m}$，重心 $\sigma_a=\dfrac{\sum p_i-\sum z_j}{n-m}$ |
| 5 | 分离 / 汇合点：解 $\dfrac{dK}{ds}=0$（或 $\sum\dfrac{1}{s-p_i}=\sum\dfrac{1}{s-z_j}$），且必须落在轨迹上 |
| 6 | 复数极点 / 零点的出射 / 入射角：由相角条件算 |
| 7 | 轨迹关于实轴对称（实系数多项式） |

### 3.3 完整例子

$$G(s)=\frac{K}{s(s+1)(s+2)}$$

- 开环极点：$0,-1,-2$；无零点；$n=3,m=0$。
- 实轴段：$[-1,0]$ 与 $(-\infty,-2]$。
- 渐近线：角度 $60^\circ,180^\circ,300^\circ$；重心 $\sigma_a=(0-1-2)/3=-1$。
- 分离点：$K=-s(s+1)(s+2)$，$\dfrac{dK}{ds}=-(3s^2+6s+2)=0$ → $s=-1\pm\dfrac{1}{\sqrt3}$。只有 $-0.423$ 落在 $[-1,0]$ 上，取它。
- 虚轴交点：由 Routh 得 $K=6$，代回辅助方程 $3s^2+6=0$ → $s=\pm j\sqrt2\approx\pm j1.414$。

![根轨迹：K/[s(s+1)(s+2)]](assets/根轨迹_三极点.svg)

读图：

- $K$ 从 0 增大，$0$ 和 $-1$ 两个极点先相向而行，在 $-0.423$ 相遇后分开，变成一对共轭复极点；
- 复极点向上 / 下走，在 $K=6$ 时穿过虚轴（$\pm j1.414$）；
- 第三个极点从 $-2$ 一路向左；
- **$K<6$ 全在 LHP（稳定），$K=6$ 临界，$K>6$ 有 RHP 极点（不稳定）**。

## 四、Routh、根轨迹、Bode 三者什么关系

| 工具 | 看什么 | 回答的问题 |
|---|---|---|
| **Routh** | 特征方程系数 | 稳不稳？$K$ 的稳定范围是多少？ |
| **根轨迹** | 极点随 $K$ 的移动 | 怎么变？从哪穿出 LHP？ |
| **Bode** | 开环频率响应 | 有多少相位 / 增益裕度？ |

三者是同一件事的三个视角：

- Routh 给**代数判据**；
- 根轨迹给**几何图像**；
- Bode 给**频域裕度**。

> 例子里的 $K=6$，Routh 算出、根轨迹看到、Bode 上对应 PM=0——三者应当一致。

## 五、常见坑

1. **系数全正只是必要条件**：$s^3+s^2+s+6$ 系数全正，但 Routh 第一列有负号，不稳定。
2. **第一列出现 0**：不能直接判，要用 $\varepsilon$ 法或乘 $(s+a)$。
3. **整行为 0**：说明有对称根，先构造辅助多项式。
4. **根轨迹画的是闭环极点**：开环极点只是起点，别把两者混为一谈。
5. **分离点要验证**：$dK/ds=0$ 的解可能不在轨迹上（本例的 $-1.577$ 就丢掉）。
6. **渐近线重心别忘零点**：$\sigma_a=(\sum p-\sum z)/(n-m)$。
7. **根轨迹默认 $K>0$**：$K<0$ 是补根轨迹，形状不同。
8. **纯延迟 / 非有理系统**：有无穷多分支，七条规则不能直接套。
