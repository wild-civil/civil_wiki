# Blender 快捷键速查

Blender 的快捷键不是一堆零散的组合键，它背后有一套统一的设计。理解这套设计，比背 48 条按键有用得多——因为忘掉某一条时，你能把它推出来。

**[打开交互速查页](assets/blender-shortcuts/index.html){:target="_blank"}** —— 48 条默认快捷键，每条配循环演示动画，支持亮暗主题切换。

---

## 核心：Blender 用的是"模态操作"，不是"选工具再拖"

绝大多数图形软件（Photoshop、SketchUp、AutoCAD）的操作是**先选工具，再对物体操作**：点"移动"工具 → 拖动物体。工具是个状态，选错了要切回来。

Blender 反过来：**按键就是启动一次操作，操作自己进入一个临时状态，接收后续输入，然后结束**。这叫**模态操作符（modal operator）**。

以移动为例，按 `G`（Grab）之后，操作进入一个临时状态，此时：

- **移动鼠标** → 物体跟着动。
- **按 `X` / `Y` / `Z`** → 锁定到对应轴。
- **再按一次同一个键** → 从全局坐标切到局部坐标。
- **直接输入数字** → 精确位移，比如依次按 `1` `.` `5` `Enter`，就是沿当前轴移动 1.5。
- **按住 `Shift`** → 移动变慢，方便微调。
- **按 `Esc` 或右键** → 取消，物体回到原位。
- **按左键** → 确认，操作结束，回到普通状态。

同样的骨架套在另外两个变换上：`R`（Rotate）转、`S`（Scale）缩放。**这三条（G/R/S）是 Blender 全部建模操作的语法基础**，学会一个就等于学会三个。

!!! tip "为什么老手几乎不用工具栏"
    因为鼠标一旦离开视口去点工具栏，就丢掉了"手已经在键盘上"的优势。模态操作符让**选择——变换——确认**全程不离开视口中心，这是 Blender 效率感的真正来源，不是快捷键本身有多神秘。

## 三条主线

### 一、看清模型：视图导航

建模时的第一个问题永远是"我现在在看哪一面"。

| 操作 | 按键 | 说明 |
|---|---|---|
| 旋转视角 | 按住**鼠标中键**拖动 | 绕一个看不见的"兴趣点"转，这个点可以移动 |
| 平移视角 | `Shift` + 中键拖动 | 移动那个兴趣点 |
| 缩放 | 滚轮，或 `Ctrl` + 中键拖动 | |
| 切到正视图 | `Numpad 1` / `3` / `7` | 前 / 右 / 顶 |
| 切到透视图 | `Numpad 5` | 在正交与透视之间来回 |
| 切到相机视角 | `Numpad 0` | |
| 聚焦选中物体 | `Numpad .` | 把视图拉到选中物体上，很常用 |
| 隐藏其余物体 | `Numpad /` | 只留选中物体，做局部细节时必备 |

!!! warning "笔记本没有小键盘怎么办"
    Blender 偏好设置里打开 `Input → Emulate Numpad`，主键盘上方的数字键就能当小键盘用。代价是主键盘数字键不能再用作其他快捷键——多数笔记本用户会接受这个交换。

**鼠标中键**是另一个新手陷阱：很多人在笔记本触控板上找不到中键。Blender 的解法是 `Preferences → Input → Emulate 3 Button Mouse`，用 `Alt` + 左键模拟中键。

### 二、选中要改的东西

| 操作 | 按键 |
|---|---|
| 全选 | `A` |
| 加选 | `Shift` + 左键 |
| 减选 | `Shift` + 左键点已选中的 |
| 循环边选择 | `Alt` + 左键点边 |
| 环形面选择 | `Ctrl` + 左键 |
| 选中相连的整体 | `L`（光标悬停在上面） |
| 反选 | `Ctrl` + `I` |
| 增大/缩小选区 | `Ctrl` + `Numpad +` / `-` |
| 按相似性选择 | `Shift` + `G` |

!!! note "左键还是右键选择"
    Blender 2.8 起**默认左键选择**。网上很多老教程说"右键选择"，那是 2.79 及更早版本的默认值。看教程时注意版本。

### 三、改形状

| 操作 | 按键 | 备注 |
|---|---|---|
| 挤出 | `E` | 建模里用得最多的一条 |
| 内插面 | `I` | |
| 环切 | `Ctrl` + `R` | 鼠标滚轮增减切线数量 |
| 倒角 | `Ctrl` + `B` | |
| 合并顶点 | `M` | 弹出的菜单里选合并方式 |
| 断开/撕裂 | `V` | |
| 分离 | `Y` | |
| 溶解（删掉但保留表面） | `Ctrl` + `X` | 和 `X`（删除，会留洞）不同 |
| 细分曲面修改器 | `Ctrl` + `1/2/3` | 数字是细分级别，`Ctrl` + `0` 关闭 |

**`X` 和 `Ctrl+X` 的区别是新手高频困惑点**：`X` 是删除并把周围的洞留着，`Ctrl+X` 是溶解——把它删掉，但让相邻面自动接合成一整片。前者会破面，后者保持表面完整。

## 速查页的用法

上面这些只是主干。完整的 48 条在速查页里，用法上有几个设计：

- **视频默认只在进入视野时加载和播放。** 页面有 48 段循环动画，如果全部同时播放，低端机会明显卡顿。滚动到哪就播到哪，离开就停。
- **点卡片标题能拿到直达链接**（比如 `#Extrude`），可以直接发给别人定位到某一条。
- **右上角可以切主题**：跟随系统 / 亮色 / 暗色。深色下更接近 Blender 本身的界面观感。
- **"收起全部"** 把 48 段说明折叠起来，只留标题和动画，方便快速浏览找感觉。

## 一句总结

Blender 的快捷键体系可以浓缩成一句话：**按一个键进入一次操作，鼠标控制方向，数字控制精度，左键确认，右键反悔**。记住这个骨架，剩下的都是填充。
