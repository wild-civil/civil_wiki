# 三维建模

机械结构件、外壳、支架，以及为了讲清楚一个结构而做的三维示意——这些都落在「三维建模」这件事上。这一块收录建模软件的用法、思路和踩坑。

它和本 wiki 里其他部分的关系是：**硬件设计决定电路长什么样，三维建模决定它装进什么壳里**。板子画完只是第一步，能不能装、怎么固定、接口开孔对不对，要靠三维模型验证。

---

## 两类软件，解决两类问题

初学者最容易卡住的地方不是"学哪个软件"，而是**没意识到三维建模分成两条完全不同的技术路线**。选错路线，后面越用越别扭。

| | 参数化实体建模 | 多边形建模 |
|---|---|---|
| **核心思路** | 先画草图，再加约束、拉伸、切除，用特征树记录每一步 | 直接推拉顶点、边、面，像捏橡皮泥 |
| **模型本质** | 数学上精确的实体（B-rep），有体积、有质量、可测量 | 一层没有厚度的表面网格 |
| **改起来** | 改参数，模型自动重建（改一个孔位直径，全部关联更新） | 改形状要手工重捏，尺寸靠目测 |
| **出工程图** | 原生支持，能标公差、出 BOM | 不支持，出不了加工图 |
| **典型用途** | 机械零件、外壳、装配体、要加工的件 | 渲染、动画、雕刻、视觉展示 |
| **代表软件** | SolidWorks、Fusion 360、FreeCAD、NX、Creo | Blender、Maya、3ds Max、ZBrush |

**一句话判断该用哪条路线**：这个模型**要不要被制造出来**？要 → 参数化实体；只要**好看、能动、能渲染** → 多边形。

两者不是替代关系。实际工作流里经常是同一个人两个都用：用 Fusion 360 把外壳设计到能加工，再用 Blender 渲染一张好看的产品图。

## 三款软件的分工

| 软件 | 定位 | 平台 | 适合谁 |
|---|---|---|---|
| **Fusion 360** | 参数化 + 直接建模 + CAM 加工 + 仿真，云端协作 | Windows / macOS | 个人、小团队、3D 打印与 CNC 加工；从设计一路做到出刀路 |
| **SolidWorks** | 参数化实体建模的行业标准，工程图与装配最强 | 仅 Windows | 机械行业从业者、要和上下游交换 STEP 图纸的场合 |
| **Blender** | 多边形建模 + 雕刻 + 动画 + 渲染，全流程开源 | Windows / macOS / Linux | 视觉呈现、渲染出图、动画演示；不用于精密制造 |

对本 wiki 涉及的硬件项目（航姿板、BLE 车钥匙、天线支架这类），**结构件用 Fusion 360 或 SolidWorks，产品展示图用 Blender** 是比较顺的组合。

!!! note "别被"免费"误导"
    Blender 是完全免费开源的，功能不打折；Fusion 360 对个人用户有免费额度但**有功能与商用限制**，条款会变，用之前查当期官方说明。SolidWorks 是纯商业授权。

## 学习顺序建议

1. **先建立空间感**：能在视图里自由旋转、缩放、对准，知道自己在看模型的哪一面。这一步不过关，后面全是瞎点。
2. **再学"从二维到三维"**：草图 → 约束 → 拉伸/旋转/切除。这是参数化建模的全部基础，比记一百个按钮有用。
3. **然后学装配**：零件之间怎么定位、怎么配合（同轴、贴合、距离）。装配约束理解错了，改一个零件会引发一连串报错。
4. **最后才是效率**：快捷键、宏、模板。**快捷键是熟练之后自然记住的，不是入门时背的**——所以下面的速查页适合当"用过一段时间后回来查"的参考，不适合当第一课。
