# 前端设计 · 知识地图

「前端设计」收录**动手改 / 看得见摸得着**的那部分前端知识：矢量图（SVG）、页面结构（HTML）、样式（CSS）、交互（JavaScript）。

这一区和站点里另一篇 **[SVG 从认识到制作](SVG/SVG从认识到制作.md)** 是**互补分工**，不是重复：

| 你想干什么 | 去哪儿 |
|---|---|
| 「SVG 的语法是什么 / `path` 的 `d` 怎么写 / `marker` 怎么用」 | [SVG 从认识到制作](SVG/SVG从认识到制作.md)（语法字典，在 *技术与编程 → 前端设计 → SVG*） |
| 「我手上有一张图，要把它改成我想要的样子」 | **本区 · SVG 动手区** ↓ |

一句话区分：**那边教你「怎么写」，这边教你「怎么改」**。修改现成的图（尤其是 AI 生成或他人绘制的）是一项独立于写语法的技能——它需要读图能力、坐标直觉和对「改一处会牵动哪些地方」的预判，而这些恰恰是语法教程不会讲的。
