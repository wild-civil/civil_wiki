# C 语言系列 · 知识地图

面向**嵌入式 / 单片机开发**的 C 语言基础系列。目标不是教你背诵语法，而是把写固件时真正决定"代码能不能跑对、能不能跨平台"的底层机制讲透：数据在内存里怎么编码、类型为什么随平台变化、内存怎么布局、编译链接怎么工作。

> 系列原则：每篇**自包含**（不依赖读其他篇才能看懂）、**普适**（例子通用，不绑定某个芯片）、**科普**（讲清"为什么"，而不是只给结论）。

## 规划中的主题

- 03 指针与数组：数组退化、指针运算、const 正确性
- 04 内存模型：栈 / 堆 / 静态区，static / volatile / const 的语义
- 05 结构体与内存对齐：padding、packed、union 类型双关
- 06 编译与链接：翻译单元、头文件守卫、extern / static、宏陷阱
- 07 数值计算的陷阱：浮点累积误差、Kahan 求和、条件数
- 08 未定义行为：未初始化、越界、悬垂指针、整数溢出、严格别名
