# 内化蓝图：Mini-INS 参考实现库（把 PSINS 拆成自己的惯导工具箱）

> **拆解 PSINS 系列第 0 篇 · 路线图**。P1–P4 已经逐篇拆开了 PSINS 的机制（轨迹生成 → 纯惯导 → 航位推算 → SINS+DR 组合），本篇回答一个更大的问题：**拆完之后怎么办？**
>
> 答案是——**内化**：把 PSINS 的架构吸收成一套自己的模块化参考实现库 **Mini-INS**。代码自写、逐行注释、零依赖、有 API 边界和回归测试，让「从公式到仿真」的理解沉淀成可复用的工程资产，而不只是几篇学习笔记。

## 一、为什么要内化（三个理由）

1. **费曼闭环**：能自己把每个模块重写出来并跑对，才算真懂。拆解是"读"，内化是"写"，读写结合才能把 PSINS 变成自己的东西。
2. **工程资产（oracle）**：一套 PC 端参考实现，是固件（C 代码）的 **golden reference**——固件在真机验证前，先在 PC 上用同一套数据对拍，这就是验证策略里 MIL/SIL/PIL 流程的 Phase 1 参考实现。
3. **算法试验台**：以后想试松/紧组合、FDI、GNSS 融合，在这套库里改一个模块就能出图，不用每次从零写。

## 二、三者关系：PSINS（参考）· Mini-INS（自写）· 固件（目标）

| | PSINS | **Mini-INS（本库）** | AHRS 固件 |
|---|---|---|---|
| 定位 | 工业级教学参考（30 年积累） | 自写参考实现库 | 量产目标实现 |
| 语言 | MATLAB | **MATLAB 主 + Python 镜像** | C |
| 可读性 | 紧凑、依赖 `global glv` 全局量 | **逐行注释、新手可读** | 嵌入式约束 |
| 代码 | 抄不得（学架构） | **自写，API 对齐 PSINS** | 独立实现 |
| 用途 | 对照 / 对拍基准 | SIL oracle、算法试验台 | 上板运行 |

**三角关系**：PSINS 是"老师"（架构与公式来源），Mini-INS 是"自己的笔记本"（可读的复述），固件是"考卷"（C 落地）。对拍链路：`PSINS 原版 ⇄ Mini-INS ⇄ 固件 C`（同一组数据，三方误差应在同一量级）。

**设计铁律**（写进库 README 开头，全系列遵守）：

1. **API 签名对齐 PSINS**——同名同参，PSINS ⇄ Mini-INS 对照零成本，对拍脚本直接复用；
2. **每行都是教学注释**——函数头给"公式层"，体内逐行标注对应公式编号；
3. **`data_classes.m` = 第 0 篇数据结构速查表的代码形态**——wiki 写字段表，库写类定义，两处同步；
4. **零依赖**——不调用 PSINS、不依赖任何工具箱，`verify/` 自证正确；
5. **确定性**——误差注入的随机游走默认关（`web=wdb=0`），保证双轨/对拍逐数字可复现。

## 四、写作规范：公式三件套（全系列统一格式）

每个公式必须配齐三件套，这是"新手可读 + 公式↔代码一一对应"的落点：

1. **符号表**：每个符号给「含义 / 单位 / 维度」——新手最大的坎是符号，先垫平；
2. **公式块**：带编号（`公式 2.3`），先用"直觉版"（如 ω×v 的物理含义），再给严格版；
3. **代码锚定**：逐行注释标注"这一行在算公式几的哪一项"，一行对一行。

**示例**（四元数 → 姿态阵 `q2cnb`，M1 的 `trans.m` 按此标准写）：

> **公式 2.3（q2cnb）**：由四元数 $q=[w;x;y;z]$ 构造姿态阵
> $$\mathbf C_b^n=\begin{bmatrix}1-2(y^2+z^2)&2(xy-zw)&2(xz+yw)\\2(xy+zw)&1-2(x^2+z^2)&2(yz-xw)\\2(xz-yw)&2(yz+xw)&1-2(x^2+y^2)\end{bmatrix}$$
>
> **对应代码**（`trans.m`，一行对一行，w=q(1), x=q(2), y=q(3), z=q(4)）：
> ```matlab
> Cbn = [1-2*(q(3)^2+q(4)^2), 2*(q(2)*q(3)-q(4)*q(1)), 2*(q(2)*q(4)+q(3)*q(1));
>        2*(q(2)*q(3)+q(4)*q(1)), 1-2*(q(2)^2+q(4)^2), 2*(q(3)*q(4)-q(2)*q(1));
>        2*(q(2)*q(4)-q(3)*q(1)), 2*(q(3)*q(4)+q(2)*q(1)), 1-2*(q(2)^2+q(3)^2)];
> ```
>
> **新手备注**：矩阵第 1 行只含 y、z 和交叉项，第 2 行只含 x、z——记不住没关系，`q2cnb` 是纯机械代换，**你只需要会查表**；真正要理解的是姿态阵的物理含义（三列 = 体轴在导航系的投影方向余弦）。

**基础转换优先**：`trans.m` 是 M1 的重中之重——姿态 / 速度 / 位置解算全部建立在其上。先讲透 NED↔body 的 `Cbn`、四元数 / 欧拉角 / 旋转矢量互转，后面机械编排才有共同语言。
