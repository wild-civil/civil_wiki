# demo_sins_dr 与 diag_m4 的区别说明

> 配套文件：`demo_sins_dr.m`（M4 验收 demo）、`diag_m4.m`（诊断脚本）、`诊断输出说明.md`（教你怎么读 diag 输出）
> 位置：`civil_wiki/docs/惯性导航/assets/miniins/demos/`

---

## 一句话

**`demo_sins_dr` 是「交作业」，`diag_m4` 是「手术灯」。**

---

## 对比表

| | `demo_sins_dr.m`（M4 验收 demo） | `diag_m4.m`（诊断脚本） |
|---|---|---|
| **目的** | 完整仿真 → 展示**结果**（对齐 P4 验收） | 复现组合链 → 展示**中间过程**（定位 bug 用） |
| **跑几条链** | **3 条**：SINS-only / DR-only / 组合(22维KF) | **1 条**：只有组合链（SINS+DR+KF+反馈） |
| **输出** | 误差对比表（att/vel/pos RMS）+ 22 维自标定汇总（dKod/dpitch/dyaw/dT/eb/db）+ **3 张图** | **不统计、不画图**，只在每次量测更新时打印一行内部量 |
| **每行打印什么** | 无（安静跑完） | `z / xfb / K6 / xk(φ·δv·δr) / P66 / P67 / P6D / P622 / dKod / dT`——滤波器的"心跳" |
| **典型输出** | `[组合(22维)] 水平位置 RMS = 44.9 m` | `量测#100 t=10.0s | z(m)=[+0.98,+1.12,+1.04] | xfb(m/s)=...` |
| **看什么用** | 验收：组合是否 ≈45.5、dKod 是否收敛 | 调试：MATLAB vs Python 参考逐行对拍，找第一个分歧点 |

---

## 相同点（所以容易混）

- **同一套仿真设置**：同一个 21 行 WAT 表、同一组误差注入（eb/db/davp/dinst/dkod）、同一套 Q/P0/R
- **同一套库函数**：`trjsimu → odsimu → insupdate → drupdate → kffk → kfupdate → 反馈`，全走 `miniins/core/`
- **都含这次修复**：KF 时间更新都改成了"只推 P 不推 x"（所以 diag 现在跑出来也应该是正常数值）

---

## 二者关系

```
demo_sins_dr = 完整版（验收报告：三链对比 + 自标定 + 图）
diag_m4     = demo 的"组合链"子集 + 中间量打印（显微镜）
```

**类比**：`demo_sins_dr` 像期末考试交卷，只看分数（44.9 m）；`diag_m4` 像监考时翻卷子看每一步怎么写的——上次组合 267 m 就是靠 diag 逐量测对比（前 100 次一致 → #105~#110 xfb 分道 → 最终锁定"推 x"）才破的案。

---

## 使用建议

- 平时跑 `demo_sins_dr` 就够了（看验收指标 + 出图）。
- 只有当结果异常（例如以后 M5 加 GNSS 量测后组合变差）才需要 `diag_m4` 打开"手术灯"看内部量。
- 配套的 `诊断输出说明.md` 就是教你怎么读 diag 输出的字典。
