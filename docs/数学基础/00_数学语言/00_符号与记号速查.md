# 符号与记号速查

> 一句话：这不是教程，是"看到符号不慌"的字典——按"长什么样、怎么读、什么意思、哪里容易坑"查。

!!! note "怎么用"
    不用从头读。看论文 / 写公式卡住时，按符号查一行即可。每个符号只给"读法 + 一句话含义 + 常见坑"，推导去对应专页。

## 一、集合与逻辑

| 符号 | 读法 | 含义 | 常见坑 |
|---|---|---|---|
| $x\in A$ | x 属于 A | x 是集合 A 的元素 | $\in$ 是"元素属于"，$\subset$ 是"集合包含" |
| $x\notin A$ | x 不属于 A | — | — |
| $\forall$ | 对任意 | 所有情况都成立 | 和 $\exists$ 连用时**顺序**会改变意思 |
| $\exists$ | 存在 | 至少有一个 | — |
| $\Rightarrow$ | 推出 | 若…则… | 反过来不一定成立 |
| $\Leftrightarrow$ | 等价 | 当且仅当 | — |
| $\triangleq$ / $:=$ | 定义为 | 左边由右边定义 | 不是"约等于" |
| $\approx$ | 约等于 | 近似相等 | — |
| $\propto$ | 正比于 | 差一个常数倍 | 不是相等 |
| $\infty$ | 无穷 | — | 不是一个数，是极限记号 |

## 二、求和与连乘

| 符号 | 读法 | 含义 |
|---|---|---|
| $\sum_{i=1}^{n} a_i$ | 西格玛，i 从 1 到 n 求和 | $a_1+a_2+\cdots+a_n$ |
| $\prod_{i=1}^{n} a_i$ | 派，连乘 | $a_1a_2\cdots a_n$ |

> 坑：$\sum$ 的上下标是"起点 / 终点"，不是乘除。

## 三、微积分

| 符号 | 读法 | 含义 | 常见坑 |
|---|---|---|---|
| $\dfrac{df}{dx}$ | f 对 x 的导数 | 变化率 / 斜率 | 不是"d 乘 f 除以 d 乘 x" |
| $\dfrac{\partial f}{\partial x}$ | f 对 x 的偏导 | 只对 x 求导，其余当常数 | 和全导数不同 |
| $\int_a^b f(x)\,dx$ | 从 a 到 b 的定积分 | 累积 / 面积 | $dx$ 表示"对 x 积分" |
| $\int f(x)\,dx$ | 不定积分 | 原函数族 | 别忘 $+C$ |
| $\nabla$ | nabla / 梯度 | 多元函数增长最快的方向 | 对标量求梯度，结果是向量 |
| $\Delta x$ | 德尔塔 x | 有限小增量 | 和微分 $dx$ 不同：一个有限，一个取极限 |
| $f'$ | f 撇 | 导数简写 | — |

## 四、线性代数

| 符号 | 读法 | 含义 | 常见坑 |
|---|---|---|---|
| $A^T$ | A 转置 | 行列互换 | $(AB)^T=B^TA^T$，顺序要反 |
| $A^{-1}$ | A 的逆 | $AA^{-1}=I$ | 只有方阵且行列式非 0 才有 |
| $\det A$ / $|A|$ | 行列式 | 是否可逆、体积缩放 | $|A|$ 也可能是绝对值 / 模，看对象 |
| $\operatorname{rank} A$ | 秩 | 线性无关的行 / 列数 | — |
| $\lambda$ | 拉姆达 | 特征值 | 也常表示波长 |
| $\mathbf v$ | 向量 v | 特征向量 | — |
| $\langle u,v\rangle$ | 内积 | 投影 / 夹角 | 和"逐元素相乘再求和"是一回事 |
| $\|x\|$ | 范数 | 长度 | 有 L1 / L2 等不同范数 |

## 五、复数与信号

| 符号 | 读法 | 含义 | 常见坑 |
|---|---|---|---|
| $j$ | 虚数单位 | $j^2=-1$ | 数学用 $i$，电路用 $j$（避开电流） |
| $\operatorname{Re} z$, $\operatorname{Im} z$ | 实部 / 虚部 | — | — |
| $|z|$ | 模 | 到原点距离 | — |
| $\arg z$ | 辐角 | 与实轴夹角 | 多值（差 $2\pi$） |
| $\angle G$ | 相角 | 复数 / 传递函数的角 | — |
| $e^{j\theta}$ | 欧拉公式 | $\cos\theta+j\sin\theta$ | 角度单位是弧度 |
| $\delta(t)$ | 冲激 | 单位冲激 | 不是普通函数，是广义函数 |
| $1(t)$ / $u(t)$ | 阶跃 | 单位阶跃 | $u(t)$ 也可能是控制输入 |

## 六、概率与统计

| 符号 | 读法 | 含义 | 常见坑 |
|---|---|---|---|
| $P(A)$ | A 的概率 | — | — |
| $P(A\mid B)$ | 条件概率 | 已知 B 时 A 的概率 | $P(A\mid B)\neq P(B\mid A)$ |
| $E[X]$ | 期望 | 加权平均 | — |
| $\operatorname{Var}(X)$ | 方差 | 波动大小 | 开方才是标准差 |
| $\sigma$ | 标准差 | — | 也常表示应力 / 奇异值 |
| $\mu$ | 均值 | — | — |
| $X\sim N(\mu,\sigma^2)$ | 服从正态 | — | 第二个参数是**方差**，不是标准差 |
| $\operatorname{Cov}(X,Y)$ | 协方差 | 两变量一起变的趋势 | 为 0 不代表独立 |

## 七、最容易读错的 8 组

1. $\partial$ vs $d$：偏导 vs 全导。
2. $\Delta$ vs $d$：有限增量 vs 极限微分。
3. $|A|$：行列式 / 模 / 绝对值，看对象。
4. $\lambda$：特征值 / 波长。
5. $\sigma$：标准差 / 应力 / 奇异值。
6. $j$ vs $i$：工程用 $j$。
7. $\arg$ vs $\angle$：都指角，$\arg$ 是复数辐角，$\angle$ 常指传递函数相角。
8. $u(t)$：单位阶跃 / 控制输入。
