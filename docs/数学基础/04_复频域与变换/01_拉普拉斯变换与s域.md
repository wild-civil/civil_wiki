# 拉普拉斯变换与 s 域

> 一句话：拉普拉斯变换把"微分方程"翻译成"代数方程"——微分变乘 $s$，积分变除 $s$。$s=\sigma+j\omega$ 是复频率：实部管衰减/增长，虚部管振荡。

!!! note "和自动控制页的分工"
    本篇讲**数学工具**：变换定义、性质、逆变换、收敛域、传递函数。
    怎么用它分析系统（极点性格、$\zeta/\omega_n$、Bode、PID）在 [自动控制 · 符号与 s 域入门](../../技术与编程/自动控制/01_符号与s域入门.md)。两篇互为表里，不重复。

## 一、为什么需要它

微分方程难解：要算积分、带初始条件、处理卷积。
拉普拉斯变换做了一件事：**把微积分变成代数**。

| 时域 | s 域 |
|---|---|
| 微分 $\dfrac{d}{dt}$ | 乘 $s$ |
| 积分 $\displaystyle\int dt$ | 除 $s$ |
| 卷积 $f*g$ | 乘 $F(s)G(s)$ |
| 微分方程 | 代数方程 |

## 二、定义与收敛域

单边拉普拉斯变换（工程默认，从 $0^-$ 开始）：

$$F(s)=\int_{0^-}^{\infty} f(t)e^{-st}\,dt,\qquad s=\sigma+j\omega$$

- $\sigma$：实部，衰减 / 增长因子；
- $\omega$：虚部，振荡角频率；
- **收敛域（ROC）**：使积分收敛的 $\sigma$ 范围。

例：

$$\mathcal{L}\{e^{-at}u(t)\}=\frac{1}{s+a},\qquad \operatorname{Re}(s)>-a$$

> ⚠️ 同一个 $F(s)$ 配不同 ROC，可能对应不同的时域信号。工程里多数是因果信号（$t<0$ 为 0），ROC 在最右极点的右边。

## 三、常用变换对

| 时域 $f(t)$ | s 域 $F(s)$ | ROC |
|---|---|---|
| $\delta(t)$ | $1$ | 全平面 |
| $u(t)$ | $\dfrac{1}{s}$ | $\operatorname{Re}(s)>0$ |
| $t$ | $\dfrac{1}{s^2}$ | $\operatorname{Re}(s)>0$ |
| $t^n$ | $\dfrac{n!}{s^{n+1}}$ | $\operatorname{Re}(s)>0$ |
| $e^{-at}u(t)$ | $\dfrac{1}{s+a}$ | $\operatorname{Re}(s)>-a$ |
| $t e^{-at}u(t)$ | $\dfrac{1}{(s+a)^2}$ | $\operatorname{Re}(s)>-a$ |
| $\sin(\omega t)u(t)$ | $\dfrac{\omega}{s^2+\omega^2}$ | $\operatorname{Re}(s)>0$ |
| $\cos(\omega t)u(t)$ | $\dfrac{s}{s^2+\omega^2}$ | $\operatorname{Re}(s)>0$ |
| $e^{-at}\sin(\omega t)u(t)$ | $\dfrac{\omega}{(s+a)^2+\omega^2}$ | $\operatorname{Re}(s)>-a$ |
| $e^{-at}\cos(\omega t)u(t)$ | $\dfrac{s+a}{(s+a)^2+\omega^2}$ | $\operatorname{Re}(s)>-a$ |

## 四、核心性质

| 性质 | 时域 | s 域 |
|---|---|---|
| 线性 | $af(t)+bg(t)$ | $aF(s)+bG(s)$ |
| 一阶导 | $f'(t)$ | $sF(s)-f(0^-)$ |
| 二阶导 | $f''(t)$ | $s^2F(s)-sf(0^-)-f'(0^-)$ |
| 积分 | $\displaystyle\int_0^t f(\tau)d\tau$ | $\dfrac{F(s)}{s}$ |
| 时移 | $f(t-a)u(t-a)$ | $e^{-as}F(s)$ |
| s 域平移 | $e^{-at}f(t)$ | $F(s+a)$ |
| 卷积 | $f(t)*g(t)$ | $F(s)G(s)$ |
| 尺度 | $f(at)$ | $\dfrac{1}{a}F\left(\dfrac{s}{a}\right)$ |

> **最重要的一条**：微分变乘 $s$，但要把初始条件减掉。零初始条件下才是干净的 $sF(s)$。

## 五、逆变换：极点决定时间形状

工程上最常用**部分分式展开**：

$$\frac{1}{s(s+1)}=\frac{1}{s}-\frac{1}{s+1}$$

逐项逆变换：

$$f(t)=1-e^{-t},\qquad t\ge0$$

极点与时间形状的对应：

| 极点位置 | 时间项 |
|---|---|
| 实极点 $p=-a$ | $e^{-at}$ |
| 共轭复极点 $-\sigma\pm j\omega$ | $e^{-\sigma t}\cos(\omega t+\varphi)$ |
| 虚轴极点 $\pm j\omega$ | 等幅振荡 |
| 右半平面极点 | 发散 |
| $n$ 重极点 | $t^{n-1}e^{-at}$ |

例：

$$\frac{1}{s^2+2s+5}=\frac{1}{(s+1)^2+4}\;\Longrightarrow\;\frac12 e^{-t}\sin(2t)$$

## 六、传递函数与稳定性

零初始条件下：

$$G(s)=\frac{Y(s)}{U(s)}$$

- 分母的根 = **极点**，决定自由响应；
- 分子的根 = **零点**，改变响应形状；
- **稳定判据**：极点全在左半平面（LHP）。

例：RC 低通

$$G(s)=\frac{1}{RCs+1},\qquad p=-\frac{1}{RC}$$

## 七、初值 / 终值定理

| 定理 | 公式 | 条件 |
|---|---|---|
| 初值 | $f(0^+)=\lim_{s\to\infty}sF(s)$ | $F(s)$ 真分式 |
| 终值 | $f(\infty)=\lim_{s\to0}sF(s)$ | $sF(s)$ 的极点全在 LHP |

> 终值定理最常用于"稳态误差"：先确认系统稳定，再算 $s\to0$。

## 八、与傅里叶的关系

令 $s=j\omega$（虚轴），拉普拉斯就退化成傅里叶：

$$G(j\omega)=\left.G(s)\right|_{s=j\omega}$$

- 拉普拉斯看**稳定性**（极点位置）；
- 傅里叶看**频率成分**（频谱）；
- 前提：ROC 包含虚轴。

详见 [频率与傅里叶直觉](02_频率与傅里叶直觉.md)。

## 九、常见坑

1. **$s$ 不是"秒"**：量纲是 1/时间。
2. **单边 vs 双边**：工程默认单边（从 $0^-$），数学教材可能用双边。
3. **初始条件**：求导性质里的 $-f(0^-)$ 别丢。
4. **ROC 不是可有可无**：它决定逆变换是否唯一。
5. **终值定理有条件**：系统不稳定时不能用。
6. **部分分式先看真分式**：分子阶数 ≥ 分母阶数时先做长除法。
