# 频率与傅里叶直觉

> 一句话：任何信号都可以拆成不同频率的正弦波；傅里叶变换就是"把信号拆成频谱"的工具，频谱告诉你"哪些频率成分强、哪些弱"。

## 一、为什么用正弦波当积木

线性时不变（LTI）系统有一个关键性质：

> 输入正弦，输出还是**同频正弦**，只是幅度和相位变了。

所以把信号拆成正弦后，系统对每个频率分别处理，再叠加即可。这就是频率分析的全部动机。

## 二、傅里叶级数（周期信号）

周期为 $T$ 的信号可以拆成基频及其谐波：

$$f(t)=a_0+\sum_{n=1}^{\infty}\left[a_n\cos(n\omega_0 t)+b_n\sin(n\omega_0 t)\right]$$

$$\omega_0=\frac{2\pi}{T}$$

- $n=1$：基频；
- $n=2,3,\dots$：二次、三次谐波；
- $a_0$：直流分量。

例：方波 = 基频 + 3 次 + 5 次 + 7 次……（只含奇次谐波，幅度按 $1/n$ 衰减）。

> 谐波越多，波形越接近方波；只用前几项时，边沿会出现振铃（吉布斯现象）。

## 三、傅里叶变换（非周期信号）

周期信号 → 离散谱；非周期信号 → 连续谱：

$$F(\omega)=\int_{-\infty}^{\infty} f(t)e^{-j\omega t}\,dt$$

$$f(t)=\frac{1}{2\pi}\int_{-\infty}^{\infty} F(\omega)e^{j\omega t}\,d\omega$$

- $\vert F(\omega)\vert$：幅度谱；
- $\angle F(\omega)$：相位谱；
- $\omega=2\pi f$。

例：

| 时域 | 频域 |
|---|---|
| 矩形脉冲 | sinc 函数 |
| 指数衰减 $e^{-at}u(t)$ | $\dfrac{1}{a+j\omega}$（洛伦兹型） |
| 正弦 $\sin(\omega_0 t)$ | 在 $\pm\omega_0$ 处两根谱线 |

## 四、采样与奈奎斯特（最容易翻车）

采样频率 $f_s$，奈奎斯特频率 $f_s/2$。

**采样定理**：要无失真恢复信号，必须

$$f_s>2f_{\max}$$

**混叠**：高于 $f_s/2$ 的频率会"折"到低频。

例：$f=50$ Hz 的信号，用 $f_s=60$ Hz 采样：

$$f_{\text{alias}}=\vert 50-60\vert=10\ \text{Hz}$$

你会在频谱里看到一个 10 Hz 的假峰——它不是真实信号。

> 工程对策：采样前加**抗混叠低通滤波器**，把 $f_s/2$ 以上的成分先滤掉。

## 五、DFT / FFT 与频率分辨率

$N$ 点 DFT 的频率分辨率：

$$\Delta f=\frac{f_s}{N}$$

第 $k$ 个频点（bin）：

$$f_k=\frac{k f_s}{N},\qquad k=0,1,\dots,N-1$$

例：$f_s=1000$ Hz，$N=1024$：

$$\Delta f\approx0.98\ \text{Hz}$$

- 想分辨更细 → 增加 $N$（更长的采样时间）；
- FFT 只是 DFT 的快速算法，复杂度从 $O(N^2)$ 降到 $O(N\log N)$。

## 六、频谱怎么看

| 成分 | 特征 | 例子 |
|---|---|---|
| 直流 | $f=0$ 的峰 | 传感器零偏 |
| 基频 | 最低的显著峰 | 50 Hz 工频、转子转速 |
| 谐波 | 基频整数倍 | 方波、电源 3/5/7 次谐波 |
| 宽带噪声 | 一片抬起的底 | 白噪声、传感器噪声 |
| 单频干扰 | 细而尖的峰 | 时钟串扰、开关电源 |

**窗函数**：直接截断会产生**频谱泄漏**（能量抹到邻近频点）。常用 Hann / Hamming 窗抑制。

**幅度换算**：实数信号的**单边谱**，非直流频点幅度要 ×2（把负频率的能量折过来）。

## 七、与拉普拉斯的关系

$$s=j\omega$$

- 拉普拉斯：看**稳定性**（极点位置）；
- 傅里叶：看**频率成分**（频谱）；
- 前提：拉普拉斯的 ROC 包含虚轴。

Bode 图就是频率响应的幅度/相位曲线：

$$\vert G(j\omega)\vert\ \text{和}\ \angle G(j\omega)$$

详见 [拉普拉斯变换与 s 域](01_拉普拉斯变换与s域.md)。

## 八、工程例子

- **振动分析**：找共振峰，避开结构固有频率；
- **电源谐波**：50 Hz 及其 3/5/7 次，判断 THD；
- **IMU 噪声**：看噪声功率谱密度（PSD）与带宽，决定低通截止；
- **音频 EQ**：按频段增减能量。

## 九、常见坑

1. **Hz vs rad/s**：$\omega=2\pi f$，差 $2\pi$。
2. **负频率**：数学上存在；实信号的正负频谱共轭对称。
3. **混叠**：采样率不够时，高频会伪装成低频。
4. **泄漏**：不整周期截断会抹宽谱线。
5. **幅度 scaling**：单边谱 / 双边谱、是否除以 $N$，不同工具约定不同。
6. **分辨率不够**：采样时间太短，两个靠近的峰分不开。
