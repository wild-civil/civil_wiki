## 一、为什么需要这一篇（与 LDO 篇的关系）

两篇是**引用关系**：本文说「LDO 仍用 LDO 篇的 SGM2034，但挂在 IU5070E 的 Vsys 之后」，不重复讲 LDO 选型细节。

## 二、KeyGo 供电的两代架构

### V1（当前：CN3165 版，无高压风险）

- **来源**：USB 5V 直供 / 单节锂电 3.7–4.2V
- **路径**：USB 5V 或电池 → LDO（SGM2034 / ME6215）→ 3.3V
- **特点**：压差最大 1.7V（USB）或 0.4V（电池末端），**无 5V 以上电压**，LDO 篇结论完整适用。充电由 **CN3165**（线性充电管理）完成。

### V2（后期：IU5070E 太阳能版）

- **新增来源**：**太阳能板，输出电压可达 7V**
- **路径**：太阳能 7V → **IU5070E（MPPT + DPPM）** → 电池 4.2V + 系统 Vsys → LDO → 3.3V
- **特点**：引入高压母线 + 多源（太阳能 / USB / 电池）动态管理。

---

## 三、IU5070E 的两个关键能力

- **MPPT（最大功率点跟踪）**：太阳能板输出随光照、温度剧烈变化，MPPT 让板子始终工作在最大功率点，避免「板子标称 7V 但实际喂不进电流」。
- **DPPM（动态电源路径管理）**：自动在 **太阳能 / USB / 电池** 之间分配功率与切换供电来源。**这恰好解决了 LDO 篇 warning 框里担心的「USB 5V 与电池 4.2V 不能直接并联」**——不用再手动做理想二极管 OR-ing，IU5070E 内部接管。

---

## 四、7V 母线与 LDO 的关系（重点澄清）

!!! info "7V 不进 LDO"

    正确接法下，**LDO 的输入是 IU5070E 输出的受管电压（Vsys / 电池轨，约 5V 或 4.2V 量级），不是 7V 太阳能母线**。所以 LDO 篇的选型（SGM2034 / ME6215）在 V2 下**基本不用改**。

**只有在设计错误、把 LDO 直接挂在 7V 母线上时**才需要高压 LDO，按 Vin_max 排查（数据见 LDO 篇 §四 对比表）：

| LDO | Vin_max | 7V 母线结论 |
| --- | --- | --- |
| **ME6215** | 18V | ✅ 最省事，直接扛 |
| **SGM2232** | 40V | ✅ 工业级冗余 |
| **XC6206** | 选 8/10V 档 | ✅ 需选对分档 |
| **SGM2034** | 7.5V | ⚠️ 太悬，7V 已近极限，太阳能尖峰会超 |
| **MCP1700** | 6V | ❌ 直接坏 |

---

## 五、DPPM 如何替代手动电源路径

LDO 篇的 warning 框提到「USB 5V 与电池 4.2V 不能直接并联，需理想二极管 OR-ing（肖特基并联或 TPS211x / LTC4412 类）」。

上 IU5070E 后，**DPPM 已接管此职责**，正常情况下无需外部 OR-ing。
