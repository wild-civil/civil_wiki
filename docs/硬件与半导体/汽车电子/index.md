# 汽车电子

> 车载电子系统：从钥匙/进入、车身控制到动力与智能化的硬件与协议。这一章聚焦"车与人 / 钥匙 / 手机如何交互"的射频与嵌入式实现。

## 本章内容

- [无钥匙进入系统](无钥匙进入系统.md)：PEPS 原理（LF 唤醒定位 + UHF 挑战应答）、与 RKE/IMMO 的区别、中继攻击与防护、数字钥匙（云/BLE/NFC）对比与趋势。
- [KeyGo：BLE 手机钥匙](KeyGo-BLE手机钥匙.md)：基于 CH582M 的实战项目落地篇——BLE 低功耗实测、NFC 应急备份、XC6206 山寨踩坑与 LDO 选型平替、抗中继设计。
- [KeyGo 调试踩坑记录](KeyGo-调试踩坑.md)：开发实战中的真实调试经历——深睡 4.4mA 根因经 `dev/pcb-v1` commit 校正为**板级外围 IC 静态电流（最大嫌疑山寨 XC6206 LDO，同程序换板差 100×）**、而非 GPIO 浮空/固件；含 CH582 四模式与 BLE Peripheral 实测功耗、IWDG/LSI 陷阱、XC6206 山寨/自激两类社区案例。
- [KeyGo 太阳能充电方案](KeyGo-太阳能充电.md)：与 AI 讨论整理——微型太阳能补电的物理、充电 IC 选型（CN3165/IU5070E/IU5060S/BQ25570 横向对比，**已联网核实+存疑标注**）、850µA 工作电流争议、DPPM/MPPT 分析、推荐拓扑与避坑。
- [非晶硅太阳能板选型（SC 系列）](非晶硅太阳能板选型.md)：SC 系列型号命名规则（Voc≈串数×0.6V、Isc 看面积）、9N 主流清单、后缀含义、虚标风险与采购验货，**型号参数待工厂规格表核实**。

## 规划中的主题

- 车身 CAN / LIN 总线基础
- UWB 数字钥匙的距离边界（distance bounding）原理

## 阅读建议

从「无钥匙进入系统」入门，建立"物理钥匙（PEPS）→ 手机钥匙（数字钥匙）→ 安全防护"的整体认知；做 KeyGo 等实战时再回到对应协议细节。
