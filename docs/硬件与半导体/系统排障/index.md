# 系统排障

电脑系统、驱动、图形子系统层面的排障实录。这一分区专门沉淀「好不容易才查清楚、值得下次直接抄」的故障案例，重点不是结论，而是**排查时间线和被证伪的假设**——那才是排障真正值钱的部分。

## 本章内容

- [VOFA+ 与 Synex 白屏/透明故障排查与修复](VOFA_Synex_白屏排障与修复.md)：一次意外黑屏断电搞坏了 AMD 显卡驱动包/组件注册状态，导致两款基于 Qt 的上位机界面不渲染。完整记录假设→验证→证伪的过程，以及 DDU + 荣耀官方驱动的最终解法。

## 规划中的主题

- Windows 更新回退显卡驱动的识别与锁定
- DWM / 桌面合成相关界面异常
- Qt 程序在 Windows 上的渲染后端选择（software / angle / native OpenGL）
