# 晶振系列

> 面向实战的晶振知识专题。从「有源 vs 无源」「二脚三脚四脚」这些让人发懵的基础分类，到**负载电容、频率公差、频率稳定度**这些直接决定电路能不能用、准不准的关键参数。

本文缘起于一个真实困惑：CH582M 接 32M 无源晶振不需要负载电容；STM32H743 飞的飞控，有人用 8M 晶振不加电容，有人加 20pF，有人加 12pF，还有人直接上 24M 有源晶振——**为什么同一颗 SoC 有三四种接法？** 本系列把这背后的逻辑讲透，而不是背参数表。

## 阅读顺序

- 想在 STM32CubeMX 里把无源 / 有源配对 → 看 [05](05_STM32CubeMX配置-有源与无源.md)（HSE 的 Crystal vs BYPASS 模式，选错 = 不起振）。
- 只想查「为什么有的板子有电容有的没有」→ 直接看 [02](02_负载电容.md) + [04](04_实战复盘-CH582M与STM32H743晶振方案.md)。
- 想彻底理清有源 / 无源 / 引脚数量 → 从 [01](01_有源与无源-晶振与振荡器.md) 开始。
- 对 ±10ppm、±30ppm 这些数字没有感觉 → [03](03_频率公差与稳定度.md)。
