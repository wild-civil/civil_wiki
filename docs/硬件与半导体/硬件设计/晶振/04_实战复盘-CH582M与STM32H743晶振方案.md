# 04 实战复盘：CH582M 与 STM32H743 的三种晶振方案

> 本系列第 4 篇（收尾）。把 01~03 的结论套回两批真实板子，给一个**拿到原理图后 30 秒判断晶振方案靠不靠谱**的检查清单。

---

## 1. 三种真实方案，一张表看懂

| 方案 | 板子/芯片 | 晶振 | 负载电容 | 为什么这么设计 |
|---|---|---|---|---|
| **A：无源 + 芯片内置电容** | CH582M / CH583 | 32 MHz / 12 pF / 10 ppm | 外置 ❌，内部可调 ✅ | 芯片自带可软件配置的匹配电容，省两颗料、软件微调 |
| **B：无源 + 外置电容** | STM32H743 飞控（8M 派）| 8 MHz / 12 pF（→外配 20pF）或 8 MHz / 8pF（→外配 12pF）| 两颗 20pF 或 12pF ✅ | ST 经典 Pierce 拓扑，电容按 $C=2(C_L-C_{stray})$ 计算 |
| **B'：无源 + 不配电容** | 部分 8M 飞控 | 8 MHz，任意 $C_L$ | 只有寄生电容 ⚠️ | 省料；频率被拉偏几十 ppm，只在不在乎时序的场景能跑 |
| **C：有源振荡器** | 部分飞控 | 24M/25M XO（如 ±10ppm）| 不需要 ✅（器件内部）| 起振快、免匹配、波形干净；贵且耗电 |

> 「有人 8M 加 20pF、有人 8M 加 12pF、有人不加、有人 24M 有源」——不是玄学，是**四组不同的工程取舍**：物料成本、频率精度需求、是否依赖 MCU 内置电容、是否愿意用有源器件，四选四的排列组合。下面逐个拆。

---

## 2. 方案 A：CH582M 为什么「不配电容也能用」

### 2.1 机制

WCH CH58x 的 32 MHz HSE 与 32.768 kHz LSE 引脚旁都集成了**可软件配置的片上电容阵列**：

- 高速：`HSECFG_Capacitance(HSECap_16p)`（或 20p 等档位）
- 低速：`LSECFG_Capacitance(LSECap_21p)`

公式与外部电容完全一致：$C_L = \frac{C_1 C_2}{C_1+C_2} + C_{stray}$，只是 $C_1=C_2$ 换成了**芯片内部的等效电容**，通过寄存器选择。于是原理图上晶振两端无需任何贴片电容，X32MI/X32MO 之间跨一颗 32M 无源晶振即完成硬件 ✅。

### 2.2 选料与配置要点（可直接抄）

1. 晶振规格：**32 MHz / 12 pF / 10 ppm（无源）**（官方推荐）；LSE 用 32.768 kHz / 12.5 pF / 20 ppm ✅。
2. 软件：配置内部电容挡位。**注意内部电容在这里等效于 [02 篇](02_负载电容.md) 公式里的 $C_1=C_2$**，所以匹配 12 pF 晶振应按 $C_{int} \approx 2(C_L-C_{stray}) = 2(12-2)=20\text{pF}$ 取 **`HSECap_20p` 档**（部分 SDK 复位默认约 16 pF 也能起振，但频率略偏低；做 BLE 想让 2.4 G 频偏最准，建议显式调到 18~20 pF 档）✅。
3. 别做 BLE 主机低功耗才需要 LSE；从机（Peripheral）可不贴 32.768 kHz，用内部 RC 兜底 ✅。
4. 判据：**如果晶振 datasheet 要求 $C_L\approx12pF$，而芯片把负载做到内部可调，那么外置电容就是多余的** —— 方案 A 省略电容的合法性来自「内部电容存在」，不是「频率无所谓」。

### 2.3 教训

如果照搬方案 A 的「不贴电容习惯」去接 STM32（内部**没有**可调负载电容的芯片），就会落入方案 B' 的坑：缓起动都可能正常，但**频偏被寄生电容主导、超出 BLE ±150 kHz 上限就断连**。**「别人不贴电容」=「别人芯片有内置电容」，抄作业以前先查自己芯片 datasheet 有没有 HSECFG 这类寄存器。** ⚠️

## 3. 方案 B / B'：STM32H743 飞控的 8M 晶振

### 3.1 B 是正规做法：两颗电容按公式来

STM32 的 HSE 振荡器是标准 Pierce 拓扑，官方 AN2867 明确给出外接负载电容计算方法：

$$
C_L = \frac{C_1 \times C_2}{C_1 + C_2} + C_{stray} ,\qquad C_1 = C_2 = 2\,(C_L - C_{stray})
$$

- 晶振 $C_L=12\text{pF}$、$C_{stray}\approx2\text{pF}$ → $C_1=C_2=20\text{pF}$ ✅（这正是你看到的「8M 配 20pF」）
- 晶振 $C_L=8\text{pF}$、$C_{stray}\approx2\text{pF}$ → $C_1=C_2=12\text{pF}$ ✅（「8M 配 12pF」）

所以**飞控上 20pF 与 12pF 两个阵营，配的是不同 $C_L$ 的 8M 晶振**，不是设计者的喜好不同。选电容前必须先定晶振型号、看它的 $C_L$。

### 3.2 B' 为什么存在：省料 vs 精度

不配电容的 8M 飞控也能转，因为：

- STM32 HSE 振荡器的增益裕量很大，寄生电容（~2-5 pF）也够晶振振荡；
- 但实际频率被拉偏（$C_L$ 与寄生不匹配的 Pullability 效应），可能偏几十 ppm；
- UART / PWM / 内部逻辑对几十 ppm 无感，所以能跑。

**代价**：一旦用这颗 8M 做 USB（需要 48 MHz 精确时钟树）或无线，频偏就直接超限。**正规产品不推荐 B'**；B' 只适合纯数字控制、对时基无要求的板子，或者是抄别人图纸时丢了电容位。

### 3.3 H743 的完整参考

ST 官方 NUCLEO-H743ZI 板用的是 **25 MHz / 6 pF / 20 ppm**（NDK NX2016SA）✅，也就是「24/25M 有源派」的另一半真相——H7 系列在官方参考上就把 HSE 做高到 25 MHz，飞控选 8M 或 24M 是各家各自 PLL 设计的选择（8M→高倍频进 480MHz PLL，24M→低倍频，各有取舍）。

## 4. 方案 C：24M 有源振荡器

有源振荡器（XO）内部 = 晶体 + 振荡电路 + 内部负载电容，**出厂已校准**，只需：

- OUT → MCU 的 OSC_IN（时钟输入脚）
- VCC / GND 供电
- 注意电平匹配：给 3.3 V 的 MCU 选 3.3 V 输出的 XO

优点：起振时间短（μs 级 vs 无源晶振 ms 级）、不受 PCB 寄生影响、频率精度由器件保证、省去电容设计。缺点：成本与功耗更高、多一路电源。适合**对起振时间/频率精度有硬要求、且不在乎这几毛钱和毫瓦级功耗**的板子（高性能飞控、网络时钟、IoT 网关）。有源晶振本身也是「外部无电容」方案，但和方案 A 是完全不同的实现（详见 01 篇第 4 节）。**落到 STM32 软件上，它必须配成 CubeMX 的 `BYPASS Clock Source` 模式（而非 Crystal 模式），否则内部放大器会与 XO 打架、起振不可靠——详见 [05 篇](05_STM32CubeMX配置-有源与无源.md)。**

## 5. 拿到原理图，30 秒判断晶振方案靠不靠谱

按顺序问 5 个问题：

1. **是无源还是有源？** 看引脚接法：接到 MCU 两根 OSC 脚的 → 无源；只有一根 OUT 进时钟脚的 → 有源（→ 直接免电容，跳过 2~4）。
2. **芯片有没有内置可调负载电容？** 搜 datasheet 关键词 `Load capacitance configurable / HSECFG` 之类。有 → 可以不贴电容（方案 A）；没有 → 必须按下一步配外部电容（方案 B）。
3. **外部电容按公式验算。** 用晶振 datasheet 的 $C_L$ 代公式 $C=2(C_L-C_{stray})$，看板子上贴的值对不对。20pF ↔ 12pF ↔ 晶振 $C_L$ 能不能对上。
4. **看晶振 ppm。** 如果这板子有蓝牙/Wi-Fi/USB/以太网 → 晶振必须 ≤10~20 ppm 档且电容正确；纯 UART/PWM → ±30 ppm 也无妨。
5. **看有没有「该有电容但没贴」的灰色地带。** 有源/内置电容 → 正常；否则就是 B'（省料将就），功能风险自担。

> 判定逻辑一句话：**「免电容」要么芯片内置（查寄存器），要么器件内置（有源），否则就是没做负载匹配——能不能用看命，能不能过认证看衰。**

## 6. 一张决策图（本系列总结）

```
需要外部晶振时钟
├─ 场景对精度/起振要求高、预算足 ──► 有源振荡器（24/25M XO，免电容）
└─ 通用低成本场景
    ├─ 芯片支持内部可调负载电容（如 CH58x）──► 无源晶振，免外置电容，软件配挡位
    └─ 芯片需要外部负载电容（如多数 STM32）──► 无源晶振 + 两颗电容（按 $C_L$ 算）
```
