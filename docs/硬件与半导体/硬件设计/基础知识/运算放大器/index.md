## 贯穿全系列的四问

拿到一个运放电路，按固定顺序问四件事，比背参数表有用：

1. **直流准不准**：Vos / Ib / CMRR / PSRR 各自贡献多大误差？（→ 03）
2. **带宽够不够**：增益带宽积 GBW 与压摆率 SR 有没有卡住信号？（→ 03）
3. **稳不稳定**：相位裕度多少，输出有没有容性负载？（→ 04）
4. **噪不噪**：噪声是否还在允许的分辨率之内？（→ 05，待写）

> 标注约定：✅ 已核实（基本公式 / 通用结论）；❓ 待核实（需查具体器件 datasheet）；⚠️ 简化或易错处。
