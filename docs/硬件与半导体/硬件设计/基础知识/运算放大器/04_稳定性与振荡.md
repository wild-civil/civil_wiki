# 04 稳定性与振荡

> 本系列第 4 篇，也是最"玄学"的一篇。目标：搞清楚**负反馈为什么会在某些条件下变成正反馈**，以及振荡了该怎么定位、怎么改。

---

## 1. 振荡的本质：负反馈变成了正反馈

回顾 [01 章](01_运放基础与负反馈.md) 的闭环增益公式：

$$A_{cl} = \frac{A}{1 + A\beta}$$

公式里那个"＋"号，前提是反馈信号与输入**反相**。但运放内部有多级放大，每级都会带来相移；频率越高，累积相移越大。

**巴克豪森判据**（✅ 振荡的两个必要条件，必须同时满足）：

1. **环路增益** $\lvert A\beta \rvert \ge 1$
2. **环路总相移** 达到 180°（此时原来的负反馈叠加 180° 相移，等效变成正反馈）

也就是说：如果环路相移达到 180° 的那个频率上，环路增益还 ≥ 1，电路就会振荡。

**工程判据**（更实用）：看开环增益曲线 $A(f)$ 与 $1/\beta$ 线的**交点**（此处 $A\beta = 1$），检查该频率处的相位距离 −180° 还有多少——这就是**相位裕度**。

## 2. 相位裕度与增益裕度

- **相位裕度 PM**：在环路增益 = 1 的频率处，相位距离 −180° 的差值。

$$PM = 180° - \lvert \phi(f_{0dB}) \rvert$$

- **增益裕度 GM**：在相位达到 −180° 的频率处，环路增益低于 0 dB 的量。

### 相位裕度与阶跃响应的对应关系（✅ 工程经验值）

| 相位裕度 | 阶跃响应表现 | 评价 |
|---|---|---|
| ≈ 90° | 无过冲，但**响应最慢** | 过于保守 |
| **60°** | 轻微过冲（约 8%），快速稳定 | ✅ **最佳折中，常用设计目标** |
| 45° | 明显过冲（约 23%），有振铃 | 可接受但余量不足 |
| 30° | 严重过冲与振铃 | 不可接受 |
| ≤ 0° | **持续振荡** | 失败 |

> 所以设计目标通常是：**相位裕度 ≥ 45°，最好做到 60°**。

## 3. 为什么电压跟随器最容易振荡

这是运放稳定性里最经典的反直觉现象。

原因：电压跟随器的 $R_f = 0$、$R_g = \infty$，噪声增益 $G_N = 1/\beta = 1$，也就是 $1/\beta$ 线落在 **0 dB**。

而 $1/\beta$ 越低，与开环增益曲线的**交点频率越高**，交点处的相位裕度就越小——**单位增益缓冲是相位裕度最恶劣的工作点**。

⚠️ **结论**：

- 很多运放**不是单位增益稳定**的（datasheet 会标注最小稳定增益，如 "stable for gain ≥ 5"）。把它们接成跟随器，就会振荡。
- 需要跟随器时，必须选 datasheet 明确标注 **"unity-gain stable"** 的型号。
- 反向应用：有些高速运放故意做成"去补偿"（decompensated），牺牲单位增益稳定性换取更高带宽和压摆率——用它们就必须保证闭环增益大于最小稳定增益。

## 4. 容性负载驱动：最常见的实际振荡源

### 4.1 机理

运放的**开环输出阻抗 $R_o$**（不是 0，典型几十 Ω）与负载电容 $C_L$ 构成一个低通网络，在环路里**额外引入一个极点**：

$$f_{p(CL)} = \frac{1}{2\pi R_o C_L}$$

这个极点贡献最多 −90° 的额外相移，直接吃掉相位裕度。长电缆、大滤波电容、ADC 的输入电容、示波器探头，都是容性负载。

### 4.2 解决方案：串联隔离电阻 $R_{iso}$

在运放输出与容性负载之间串一只小电阻（典型 10 ~ 100 Ω），把 $C_L$ 与运放输出级"隔开"，再由反馈环路在 $R_{iso}$ **之前**取样：

- $R_{iso}$ 与 $C_L$ 形成的极点被推到环路之外（因为反馈取自 $R_{iso}$ 前端）
- 代价：$R_{iso}$ 与负载形成分压，输出幅度会有轻微下降（负载电流会在 $R_{iso}$ 上产生压降）

✅ 这是解决容性负载振荡的标准做法，几乎不增加成本。

⚠️ 注意：反馈取样点必须在 $R_{iso}$ **之前**（即直接从运放输出脚取），否则 $R_{iso}$ 的压降也进入环路，隔离失效。

??? note "$R_{iso}$ 该取多大？"
    工程经验值 **10 ~ 100 Ω**，但它同时受上下两个边界夹住，不是随便取：

    **下限（太小不行）**：$R_{iso}$ 要足够大，才能把 $R_{iso}$-$C_L$ 形成的极点推离环路带宽、恢复相位裕度。一般从 10 Ω 起试，用示波器看阶跃响应的过冲/振铃是否消失。

    **上限（太大不行）**：$R_{iso}$ 与负载 $R_L$ 串联分压，负载端实际得到的幅度比例为：
    $$\frac{V_{load}}{V_{out}} = \frac{R_L}{R_L + R_{iso}}$$
    
    例：$R_{iso} = 50\ \Omega$、$R_L = 50\ \Omega$ 时，负载只拿到一半幅度——**增益直接掉一半**。所以驱动低阻负载（如 50 Ω 电缆）时 $R_{iso}$ 必须远小于 $R_L$。

    **没有压降预算时怎么办**（精密直流场合）：
    - 在 $R_{iso}$ 之后再串一级跟随器，构成"输出-反馈"双环路隔离（反馈取自最终输出，压降被环路校正掉）；
    - 或选用 datasheet 明确标注"容性负载驱动能力 / capacitive load drive"的运放。

    ❓ 精确取值建议用 SPICE 扫 $R_{iso}$ 观察相位裕度，或直接用器件 datasheet 的推荐值，别纯靠试。

## 5. 反相端对地电容：另一个高频坑

在反相放大器的反相输入端（$u_-$ 节点），任何对地电容 $C_{in}$（包括运放输入电容、PCB 寄生电容、长走线）都会与反馈电阻 $R_f$ 作用，使**噪声增益在高频抬升**：

$$G_N(j\omega) = 1 + \frac{R_f}{R_g \parallel \frac{1}{j\omega C_{in}}}$$

高频时 $R_g$ 被 $C_{in}$ 旁路，$G_N$ 上升 → $1/\beta$ 曲线在高频"翘起来" → 交点频率上移 → 相位裕度恶化 → 振荡。

**对策**：

1. 减小反相节点寄生电容：**缩短走线、避免在反相节点铺大面积铜皮**（这是 PCB 布局上非常实用的一条）。
2. 在 $R_f$ 上**并联一只小反馈电容 $C_f$**（几 pF），主动给高频提供通路，压平噪声增益峰值。✅ 这是标准补偿手段。

## 6. 补偿手段清单

| 问题 | 对策 | 代价 |
|---|---|---|
| 容性负载振荡 | 输出串 $R_{iso}$（10~100 Ω），反馈取自 $R_{iso}$ 前 | 负载端幅度略降 |
| 反相节点寄生电容 | 缩短走线 / 减少铺铜；并在 $R_f$ 上并小 $C_f$ | $C_f$ 会**降低带宽** |
| 单位增益不稳定 | 换 unity-gain stable 型号；或人为提高噪声增益（在 $R_g$ 上并电阻/电容）| 提高噪声增益会放大失调误差 |
| 驱动长线 / 大电容 | 输出加缓冲级（如专用缓冲器或射随器）| 增加器件 |
| 带宽不够但想稳定 | 选更高 GBW 且单位增益稳定的运放 | 成本、功耗 |

## 7. 排查方法论

振荡的表现很有迷惑性——**它可能看起来像"噪声大"、"精度差"、"发热"，而不是明显的正弦波**。

### 7.1 怎么判断"是不是振荡了"

| 现象 | 提示 |
|---|---|
| 输出有固定频率的毛刺，且不随输入变化 | 高度怀疑振荡 |
| 静态输入下输出不干净 | 振荡或噪声 |
| 运放**异常发热**、电源电流明显偏大 | 振荡的典型伴随现象（输出级在高频来回摆动）|
| 用手触摸芯片/靠近探头，波形幅度变化 | 振荡（寄生参数被扰动）|

### 7.2 诊断链（按此顺序排查）

1. **确认供电与去耦**：每个电源脚就近 0.1 µF 去耦电容，且地回路短。✅ 这一步能解决相当比例的"莫名振荡"。
2. **确认是不是真的振荡而非噪声**：用示波器看频谱或频率——振荡是**单一频率的尖峰**，噪声是宽带。
3. **确认工作点**：是否违反最小稳定增益？是否超出输入共模范围或输出摆幅？
4. **找容性负载**：输出是否接了长线、大电容、ADC？加 $R_{iso}$ 试试。
5. **找反相节点寄生电容**：PCB 上反相输入走线是否过长、下方是否有铺铜？
6. **降低噪声增益或加 $C_f$**：在 $R_f$ 上并联几 pF 电容，看是否平息。

### 7.3 一条经验原则

> 如果振荡频率**远高于**信号带宽，多半是稳定性问题（相位裕度不足）；如果振荡频率在信号带内，先怀疑去耦和布局。
