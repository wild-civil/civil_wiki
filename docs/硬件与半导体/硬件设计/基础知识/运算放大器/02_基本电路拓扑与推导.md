# 02 基本电路拓扑与推导

> 本系列第 2 篇。目标：把常用运放电路的**传递函数逐个推出来**，并给出每个电路的设计约束与踩坑点。
> 各电路的标准符号电路图见速查篇《[基本元器件 - 运算放大器](../基本元器件-运算放大器.md)》，本文聚焦"为什么是这个公式"和"设计时该注意什么"。

---

## 0. 通用分析套路

所有线性运放电路都可以用同一套三步法解出来，不需要背公式：

1. **虚短**：$u_+ = u_-$（前提：负反馈 + 线性区，见 [01 章](01_运放基础与负反馈.md)）
2. **虚断**：流入两个输入端的电流为 0
3. **对节点列 KCL**（基尔霍夫电流定律）

只要掌握这三条，任何拓扑都能现推。下面逐个演示。

---

## 1. 电压跟随器（Buffer）

**连接**：输出直接接到反相端 $u_-$；信号接同相端 $u_+$。

![电压跟随器电路](assets/电路-电压跟随器.svg)

**推导**：

$$u_- = u_o,\quad u_+ = u_{in}$$
$$虚短 \Rightarrow u_o = u_- = u_+ = u_{in} \Rightarrow A_{cl} = 1$$

**特性与用途**：

| 项目 | 说明 |
|---|---|
| 增益 | 恒为 1 |
| 输入阻抗 | 极高（理想 $\infty$）|
| 输出阻抗 | 极低（理想 0）|
| 用途 | **阻抗变换 / 隔离**：把高阻信号源（如传感器、分压器）变成低阻驱动能力，去驱动 ADC、长线、后级负载 |

⚠️ **坑**：电压跟随器是**最容易振荡**的运放电路（噪声增益 = 1，相位裕度最恶劣）。选用时必须确认器件标注"单位增益稳定"（unity-gain stable），详见 [04 章](04_稳定性与振荡.md)。

---

## 2. 同相放大器

**连接**：信号 → $u_+$；$R_g$ 从 $u_-$ 接地；$R_f$ 从输出 $u_o$ 反馈到 $u_-$。

![同相放大器电路](assets/电路-同相放大器.svg)

**推导**：

由虚短，$u_- = u_+ = u_{in}$。而 $u_-$ 是 $R_f$、$R_g$ 对输出的分压：

$$u_- = u_o \cdot \frac{R_g}{R_g + R_f}$$

联立：

$$u_{in} = u_o \cdot \frac{R_g}{R_g + R_f}
\quad\Rightarrow\quad
\boxed{u_o = u_{in}\left(1 + \frac{R_f}{R_g}\right)}$$

**特性**：

| 项目 | 说明 |
|---|---|
| 闭环增益 | $1 + R_f/R_g$，**永远 ≥ 1** |
| 输入阻抗 | 极高（≈ $R_{in}(1+A\beta)$，MΩ ~ GΩ 级）|
| 共模电压 | $u_{CM} = u_{in}$，⚠️ **随输入信号变化** |
| 优点 | 输入阻抗高，适合高阻信号源 |
| 缺点 | 共模电压跟着输入跑，需确认输入共模范围覆盖信号 |

⚠️ **坑**：
- 想做衰减（增益 < 1）不能用同相结构，只能用反相结构或先分压再跟随。
- 输入共模范围（CMVR）是常见限制。若信号接近电源轨，普通运放输入级会失效，需选轨至轨输入（RRI）运放。

---

## 3. 反相放大器

**连接**：$u_+$ 接地；信号经 $R_{in}$ 接到 $u_-$；$R_f$ 从 $u_o$ 反馈到 $u_-$。

![反相放大器电路](assets/电路-反相放大器.svg)

**推导**：

由虚短，$u_+ = 0 \Rightarrow u_- = 0$——这就是**虚地**（电位为 0，但不要当成真正的地）。

对 $u_-$ 节点列 KCL（虚断 ⇒ 流入运放的电流为 0）：

$$\frac{u_{in} - 0}{R_{in}} + \frac{u_o - 0}{R_f} = 0$$

$$\boxed{u_o = -u_{in}\cdot\frac{R_f}{R_{in}}}$$

**特性**：

| 项目 | 说明 |
|---|---|
| 闭环增益 | $-R_f/R_{in}$，**可大于或小于 1**（含衰减）|
| 输入阻抗 | **≈ $R_{in}$**，不是无穷大 ⚠️ |
| 共模电压 | $u_- \approx 0$，共模几乎不变 |
| 优点 | 共模电压固定，对 CMRR 要求低；可做衰减 |
| 缺点 | 输入阻抗由 $R_{in}$ 决定，会加载信号源；信号被反相 |

⚠️ **坑**：
- 输入阻抗 = $R_{in}$。若信号源内阻不小，会形成分压造成增益误差——选 $R_{in}$ 时要远大于信号源内阻。
- $R_{in}$ 也不能无限大：太大会放大偏置电流误差和噪声，见 [03 章](03_关键参数与误差预算.md)。

??? note "为什么反相放大器的输入阻抗是 Rin，而不是无穷大"
    关键在于反相端是**虚地**：$u_-$ 被负反馈钳位在 0 V，但它**并不是悬空的**——信号电流会实打实地经 $R_{in}$ 流进这个节点。

    从信号源看进去：
    $$Z_{in} = \frac{u_{in}}{i_{in}} = \frac{u_{in}}{u_{in}/R_{in}} = R_{in}$$

    这与同相放大器形成鲜明对比：同相结构的信号直接进 $u_+$ 引脚，运放输入级本身阻抗极高，所以输入阻抗是 MΩ ~ GΩ 级。

    **工程结论**：
    - 需要高输入阻抗（如传感器、高阻分压器）→ 用**同相**结构，或前级加电压跟随器；
    - 用反相结构时，$R_{in}$ 要**远大于信号源内阻**（一般 ≥ 10 倍）才能忽略分压误差；
    - 但 $R_{in}$ 也不能一味取大，太大又会放大偏置电流误差与电阻热噪声——这就是运放设计里典型的"两头堵"，需要在 [03 章](03_关键参数与误差预算.md) 的误差预算里权衡。

## 4. 加法器（反相求和）

**连接**：多路信号各经一只电阻 $R_1, R_2, \dots$ 汇入虚地节点 $u_-$；$R_f$ 反馈。

**推导**（对虚地节点列 KCL）：

$$\frac{v_1}{R_1} + \frac{v_2}{R_2} + \cdots = -\frac{u_o}{R_f}$$

$$\boxed{u_o = -R_f\left(\frac{v_1}{R_1} + \frac{v_2}{R_2} + \cdots\right)}$$

若各路电阻相等（$=R$），则 $u_o = -\dfrac{R_f}{R}(v_1+v_2+\cdots)$。

**特性**：各路**互相独立**（因为都汇入虚地，彼此不串扰），这是反相求和的最大优点。缺点是输出反相、各路输入阻抗等于各自的 $R_i$。

---

## 5. 减法器 / 差动放大器

**连接**：$v_1$ 经 $R_1$ 到 $u_-$，$R_f$ 反馈；$v_2$ 经 $R_2$ 到 $u_+$，$R_3$ 从 $u_+$ 接地。

![减法器（差动放大器）电路](assets/电路-减法器.svg)

**推导**（用叠加原理）：

先令 $v_2 = 0$，此时是反相放大器：$u_{o1} = -\dfrac{R_f}{R_1}v_1$

再令 $v_1 = 0$，此时是同相放大器（输入被 $R_2, R_3$ 分压）：$u_{o2} = \left(1+\dfrac{R_f}{R_1}\right)\cdot\dfrac{R_3}{R_2+R_3}v_2$

叠加后，当电阻满足**匹配条件** $\dfrac{R_f}{R_1} = \dfrac{R_3}{R_2}$ 时：

$$\boxed{u_o = \frac{R_f}{R_1}(v_2 - v_1)}$$

⚠️ **核心坑——CMRR 完全取决于电阻匹配**：

这个电路的共模抑制能力不是运放给的，而是**四个电阻的匹配精度**给的。若电阻有公差，共模信号就无法完全抵消。

| 电阻精度 | 理论 CMRR 上限（近似）|
|---|---|
| 1% | ≈ 40 dB |
| 0.1% | ≈ 60 dB |
| 0.01% | ≈ 80 dB |

所以高精度差分测量**不要**用分立电阻搭减法器，应该用集成的**仪表放大器**（见第 8 节），或者至少用匹配电阻网络（如 4 电阻一体的排阻）。
❓ 具体 CMRR 与电阻公差的关系需用实际器件与电阻规格核算。

---

## 6. 积分器

**连接**：反相结构，把反馈电阻换成电容 $C$。

**推导**：流过 $R_{in}$ 的电流全部给电容充电：

$$i = \frac{u_{in}}{R_{in}},\qquad u_o = -\frac{1}{C}\int i\,dt$$

$$\boxed{u_o(t) = -\frac{1}{R_{in}C}\int u_{in}(t)\,dt + u_o(0)}$$

频域形式：$H(j\omega) = -\dfrac{1}{j\omega R_{in}C}$，增益随频率升高而下降（−20 dB/dec）。

⚠️ **实际电路必须并联一只大电阻 $R_f$**：

理想积分器在直流（$\omega \to 0$）增益无穷大，意味着**运放的任何输入失调电压都会被持续积分，最终把输出推到饱和**。并联 $R_f$ 后，实际电路是一个低通放大器：

$$直流增益 = -\frac{R_f}{R_{in}},\qquad 转折频率\ f_c = \frac{1}{2\pi R_f C}$$

低于 $f_c$ 是反相放大，高于 $f_c$ 才是积分。✅ 这是所有实际积分电路的标准做法。

---

## 7. 微分器

**连接**：反相结构，把输入电阻换成电容 $C$。

**推导**：

$$i = C\frac{du_{in}}{dt},\qquad u_o = -R_f i$$

$$\boxed{u_o = -R_f C\frac{du_{in}}{dt}}$$

⚠️ **两个致命问题**：

1. **高频增益无限上升** → 把高频噪声极度放大；
2. **相移导致不稳定** → 极易振荡。

**实用做法**：在输入电容上**串联一只小电阻 $R_s$**，限制高频增益上限为 $-R_f/R_s$。此时电路在低频是微分器、高频退化成反相放大器，稳定性和噪声都可控。

---

## 8. 仪表放大器（Instrumentation Amplifier）

**结构**：经典三运放结构——前级两个同相放大器提供高输入阻抗和差分增益，后级一个差动放大器完成差分到单端转换。

**增益公式**（标准三运放，$R_1$ 为内部匹配电阻，$R_g$ 为外接增益电阻）：

$$\boxed{u_o = \left(1 + \frac{2R_1}{R_g}\right)(v_2 - v_1)}$$

**为什么它比"分立电阻减法器"强**：

| 对比项 | 分立减法器 | 集成仪表放大器 |
|---|---|---|
| 输入阻抗 | 有限（$=R_1$，且两端不等）| **极高**（两个同相端）|
| CMRR | 完全依赖外部电阻匹配（1% → ≈40 dB）| 内部激光配阻，典型 80 ~ 120 dB ✅ |
| 增益设置 | 需同时改 4 只电阻 | **改一只 $R_g$** |
| 适合场景 | 精度要求不高的差分转单端 | 微弱差分信号（应变片、电桥、电流采样）|

⚠️ **坑**：三运放结构有著名的**输入共模范围菱形限制**（diamond plot）——增益越大，允许的共模范围越窄。选型时一定要查 datasheet 的共模范围图，否则会出现"信号幅度明明不大、输出却异常"的怪现象。❓ 具体边界以器件 datasheet 的菱形图为准。

## 9. 设计要点速查表

| 电路 | 增益 | 输入阻抗 | 共模电压 | 典型用途 | 主要坑 |
|---|---|---|---|---|---|
| 电压跟随器 | 1 | 极高 | = 输入 | 阻抗隔离 / 驱动 | 最易振荡，需单位增益稳定 |
| 同相放大 | $1+R_f/R_g$（≥1）| 极高 | = 输入 | 高阻信号放大 | 共模随输入变，注意 CMVR |
| 反相放大 | $-R_f/R_{in}$ | ≈ $R_{in}$ | ≈ 0 | 衰减 / 反相 / 求和 | 输入阻抗不高 |
| 加法器 | 各路加权求和 | 各路 $R_i$ | ≈ 0 | 多路叠加、DAC 后级 | 输出反相 |
| 减法器 | $\frac{R_f}{R_1}(v_2-v_1)$ | 有限 | 随输入 | 差分转单端 | CMRR 靠电阻匹配，精度差 |
| 积分器 | $-1/(j\omega R_{in}C)$ | ≈ $R_{in}$ | ≈ 0 | 波形变换、低通 | 直流饱和，需并 $R_f$ |
| 微分器 | $-j\omega R_f C$ | 容性 | ≈ 0 | 边沿检测 | 噪声与振荡，需串 $R_s$ |
| 仪表放大器 | $(1+2R_1/R_g)$ | 极高 | 受菱形图限制 | 微弱差分信号 | 共模范围受限 |
