# 电源切换与防倒灌

当系统有多个供电来源（比如太阳能板 + USB、主电池 + 备份电源、适配器 + 电池），你需要决定**谁优先、谁备份、谁不能往谁那儿倒灌**。本系列把这件事情讲透：从最底层的 MOS 体二极管，到栅极怎么驱动，再到一张能直接投产的实战电路。

> 核心结论先放这：**双向防倒灌用 PMOS 背靠背，必须漏极对漏极（D-D）；源极对源极（S-S）是错误接法，VIN 高于输入时会倒灌。**

## 什么时候你需要它

- 多电源自动切换（ORing）：谁有电谁供，互不打架。
- 电池供电设备插适配器时，不能让适配器往电池里猛灌、也不能让电池往适配器倒灌。
- 太阳能/USB 双输入充电管理。
- 热插拔、冗余电源、主备切换。

如果只关心「单向别让负载倒灌进电源」，单颗 PMOS（源极接输入、漏极接输出）就够了；要**双向**都堵死，才需要背靠背两管。
