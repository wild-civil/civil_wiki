# Altium Designer 快捷键速查

快捷键能大幅提速。下面为常用默认值，分场景列出。

> ⚠️ **重要**：Altium 快捷键可在 `Tools → Customize`（或右键工具栏 → Customize）里**完全自定义**；菜单项后面的下划线字母（如 *Repour All* 的 A）即当前版本的加速键，**会随版本略有差异**。下表以常见默认值为准，若某条和你版本不符，以菜单实际显示为准。

## 一、放置（Place，前缀 `P`）

| 快捷键 | 功能 |
|---|---|
| `P` → `G` | 放置铺铜 Polygon Pour |
| `P` → `F` | 放置实心填充 Fill |
| `P` → `T` | 交互式布线（放走线 Track） |
| `P` → `V` | 放置过孔 Via |
| `P` → `P` | 放置焊盘 Pad |
| `P` → `L` | 放置线条（非电气 Line） |
| `P` → `D` | 放置尺寸标注 Dimension |
| `P` → `N` | 放置网络标号（部分版本） |

## 二、铺铜操作（Tools → Polygon Pours，前缀 `T` → `G`）

| 快捷键 | 功能 | 说明 |
|---|---|---|
| `T` → `G` → `A` | 重铺全部 Repour All | 改板后必做 |
| `T` → `G` → `M` | 重铺选中 Repour Selected | 先选中铺铜；加速键随版本可能为 S/R |
| 右键铺铜 → `Polygon Actions` | Repour / Shelve / Resume | 重铺 / 搁置 / 恢复显示 |
| `Shift`+`Space`（画铺铜时） | 切换拐角模式 | 直角 / 45° / 圆弧 |

> 搁置（Shelve）后铺铜只显示边框，操作大板更流畅；出图前务必 Resume 并再 Repour。

## 三、DRC 与校验（Tools，前缀 `T`）

| 快捷键 | 功能 |
|---|---|
| `T` → `D` → `R` | 运行 Design Rule Check（DRC） |
| `T` → `D` → `C` | 部分版本：运行在线 DRC 校验 |

## 四、布线时的临时键（交互式布线中）

| 快捷键 | 功能 |
|---|---|
| `Tab` | 打开布线属性（线宽/层/过孔） |
| `Shift`+`Space` | 切换布线拐角模式（45°/90°/圆弧） |
| `Space` | 切换拐角方向 |
| `Ctrl`+ 单击 | 在当前位置打过孔换层 |
| `Backspace` | 撤销上一段布线 |
| `*` / `-`（小键盘） | 切换到上一层 / 下一层 |

## 五、视图与显示（View，前缀 `V`）

| 快捷键 | 功能 |
|---|---|
| `V` → `D` | 整板适配（Fit Document） |
| `V` → `F` | 适应选中对象（Fit Selected） |
| `Ctrl` + 滚轮 | 缩放 |
| `Shift`+`S` | 单层显示模式切换（只看当前层） |
| `V` → `B` | 翻转板子（3D 视角下看底面） |
| 右键拖动 / 中键拖动 | 平移视图 |

## 六、选择与编辑

| 快捷键 | 功能 |
|---|---|
| `Ctrl`+`A` | 全选 |
| `S` | 选择菜单（全部 / 板 / 网络 / 连接等） |
| `E` → `D` 或直接 `Delete` | 删除（E→D 进入删除模式后点对象） |
| `M` | 移动菜单（移动 / 移动选中 / 拖动） |
| `Ctrl`+`Z` / `Ctrl`+`Y` | 撤销 / 重做 |
| `Ctrl`+`C` / `Ctrl`+`V` / `Ctrl`+`X` | 复制 / 粘贴 / 剪切 |

## 七、元件操作（放置元件时 / 选中后）

| 快捷键 | 功能 |
|---|---|
| `Space` | 旋转元件（90°） |
| `X` / `Y` | 水平 / 垂直镜像（翻面用，底层元件常需） |
| `L` | 翻到另一面（Top ↔ Bottom） |
| `A` | 对齐菜单（Align） |

## 八、测量与其它

| 快捷键 | 功能 |
|---|---|
| `Ctrl`+`M` | 测量两点距离（`Reports → Measure` 亦可） |
| `G` | 循环切换捕获栅格（Snap Grid） |
| `Ctrl`+`G` | 设置栅格 |
| `Shift`+`E` | 切换电气栅格（Electrical Grid） |
| `Tab` / `F11` | 打开选中对象属性面板 |

## 提示

- 记不住就记前缀：`P`=放置、`T`=工具、`V`=视图、`S`=选择、`M`=移动、`A`=对齐；
- 真正高频的是：**`P`→`G` 铺铜、`T`→`G`→`A` 重铺、`T`→`D`→`R` 跑 DRC** —— 铺铜改动后这套三连必须走一遍。
