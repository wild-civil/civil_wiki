# 嘉立创 EDA 元件库与封装

嘉立创 EDA（LCEDA）最大的爽点是「不用自己建库」——立创商城的真实元件直接拖进来就有封装和 3D 模型。但有些时候你还是得自己画封装。

## 一、库的两层结构

- **元件（Part）**：原理图符号 + 封装 + 3D 模型 + 真实料号（来自立创商城）；
- **封装（Footprint）**：PCB 上焊盘的实际图形，是「画 PCB」真正用到的东西。

> 在嘉立创 EDA 里搜一个料号（如 `C25804`）放进去，原理图符号、封装、3D 一次到位；BOM 直接带料号，下单 SMT 时连元件都不用另买。

## 二、什么时候需要自己画封装

| 场景 | 怎么做 |
|---|---|
| 用立创商城现有料号 | 直接搜，无需画封装 |
| 商城没有的定制件 / 国产替代 | 用「封装向导」或手动画 |
| 非常规焊盘（异形、散热焊盘） | 手动画 + 核对数据手册尺寸 |
| 想统一管理公司私有库 | 建「个人库 / 团队库」保存 |

## 三、画封装的关键尺寸（以数据手册为准）

- 单位切换：`Ctrl+Q`（或界面右上角）在 mm / mil 间切换；
- 焊盘尺寸 = 数据手册「推荐 Land Pattern（焊盘图形）」；
- 丝印框画在 `Top Overlay`，比焊盘外扩 0.2~0.5mm，**别压到焊盘**；
- **1 脚标识**（圆点 / 斜角）必须标，否则贴片会反；
- 画完在「封装管理器」里预览 3D，确认和实物对得上。

## 四、封装与 3D 模型

- 商城元件自带 3D 模型；自己画的封装可「关联 3D 模型」（.step / .wrl）；
- 出板前在 3D 视图转一圈，检查元件高度干涉、极性方向。
