怎么用：拖动两个滑块——φ 是向量相对旧 X 轴的初始角度，θ 是旋转角。左图向量转（主动旋转，坐标系不动）；右图坐标系转（被动旋转，向量不动）。重点观察两侧矩阵第 1 列（绿框）如何对应「旧 X 轴单位向量」的去向：主动时旧 X 转到 +θ，被动时旧 X 相对新系落在 −θ。当 θ > φ 时，右图 Y′ 投影变负（红线向下）。

① 主动旋转 R(θ)

坐标系不动，向量逆时针旋转 +θ (夹角变成 φ + θ)

主动矩阵 R(θ) — 绿框为第 1 列 [e₁ 去向]
R = [
cosθ -sinθ 0 sinθ cosθ 0 0 0 1
]
v' = [cos(φ+θ), sin(φ+θ)]ᵀ

② 被动旋转 C₁² (方向余弦)

向量不动，坐标系转 +θ → 相对角 (φ − θ)，当 θ > φ 时 Y' 投影下沉变负

被动矩阵 C₁² = R(θ)ᵀ — 绿框为第 1 列 [旧 e₁ 在新系坐标]
C = [
cosθ sinθ 0 -sinθ cosθ 0 0 0 1
]
v' = [cos(φ−θ), sin(φ−θ)]ᵀ
第一列法则（几何对齐）：
1. 矩阵第 1 列（绿框）永远等于把旧 X 轴单位向量 [1,0,0]ᵀ 喂给矩阵的结果。
2. 主动旋转时，旧 X 轴转到 +θ 处 → 第一列是 [cosθ, sinθ]ᵀ；被动旋转时，旧 X 轴相对新系落在 −θ 处 → 第一列是 [cosθ, −sinθ]ᵀ。这正是主动矩阵与被动矩阵互为转置的几何来源。
