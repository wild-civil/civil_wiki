    KeyGo 太阳能充电方案¶

    本文整理自与 AI（豆包）关于「KeyGo 实体钥匙端如何用微型太阳能板补电」的多轮讨论，经本人交叉核实与工程判断后重写。

    来源与可靠性说明（务必先读）

    • 标注约定：✅ = 重大已确认结论 / 整节参数来自官方 datasheet；❓ = 待 datasheet 或实测核实；⚠️ = 存疑或需谨慎（如豆包/deepseek说法未逐一证实、设计前须以官方资料为准）。一般参数行不再逐条标 ✅，以所在小节标题的 ✅ 为准。
    • 本讨论是一份"调研草稿"，不是定稿设计。豆包曾混淆 850μA（实为 IQ 静态电流）与充电工作自耗、把 ICC（充电输出电流）当成芯片自耗——相关数字不能当作设计依据直接抄用。
    • 豆包讨论基于"整机 388µA"负载假设，而 KeyGo 实测（见 KeyGo 调试踩坑记录）自焊板未优化深睡达 4.4mA、开发板修 GPIO 后 35µA——三者量级差异巨大，所有"净充电收益"计算必须以你自己的实测值为准，不要直接套豆包的 388µA。
    • 关键器件选型与电流参数，一律以官方 datasheet + 你的实测为准。

    1. 太阳能补电的基本物理¶

    充电本质是"电流往电池转移"。只要太阳能输出电流 > 整机静态耗电，电池就在净储能；否则电池只是被延缓放电。

    净充电公式

    净充电电流: I_net = I_pv - I_load - I_ic-self

    • I_pv：太阳能板当前光照下的实际输出电流（非标称值，看真实工况）
    • I_load：KeyGo 整机平均耗电（含 MCU + 常开 LDO + 未断电外设）
    • I_ic-self：充电 IC 自身消耗（工作模式 / 待机 / 无光漏电，三值不同，见 §3）

    当 I_net > 0 持续成立，才能实现"永久续航 / 不换电池"目标。

    不同工况的电流量级（以 ETC / SC 系列非晶硅微型板为例）¶

    工况 太阳能输出 I_pv 能否补电（取决于 I_load）
    夏日暴晒挡风玻璃 十几 mA 轻松净充
    白天车内散射光（树荫/遮阳膜） 1~4 mA 中等光照，需 I_load 够低
    阴天 / 地下车库门口 80µA ~ 1.6mA 最致命区间，I_load 必须压到 µA 级
    完全无光车库 ≈0 纯电池供电，回到纯电池模型

    车载钥匙 90% 时间是"阴天/散射光几百 µA~几 mA"区间，所以弱光下的 I_net 正负决定了方案成败——这也是后文所有论证的焦点。

    2. 充电 IC 选型对比¶

    2.1 候选芯片一览¶

    先记结论（经本人核实）

    • IU5070E（上大科技/上海智浦欣，EQA16）：真实存在，内置 MPPT（有效充电低至 1mA） + DPPM 动态电源路径 + 零功耗 SYSOFF 运输模式 + OVP 8.6V + 电池泄漏 7~9µA，工作电压 3.6~8.6V，耐压 33V，最大 1.5A。车载弱光非晶硅板（Voc 5.4~6V）适配性最好。
    • IU5060S（同厂，SOT23-5L）：真实存在，600mA，无 MPPT，电池泄漏 0.5µA，33V 耐压。面积小、自耗极低，但弱光利用率差。
    • CN3165（如韵微电子）：真实存在、带 MPPT，官方 datasheet 已提取完整参数（见 §3.5）；其输入耐压仅 ~6V，SC-10 串板需外加钳位 ⚠️。
    • BQ25570（TI）/ AEM10941（e-peas）：知名升压型能量采集 IC，nA 级工作电流，可收集几十 µA 光伏电流，是"永久续航顶配"，但外围复杂、成本高。

    电流设定方式（IU5070E 已通过 datasheet 确认 ✅）

    • IU5070E：ICC = KISET / RISET = 400 AΩ / RISET，ISET 引脚外置电阻设定恒流充电电流。RISET=400Ω→1A, 4kΩ→100mA。
      • CN3165：同样用 ISET（或 Riset）引脚。datasheet 确认：VISET=1.205V（恒流模式）/ 0.12V（预充模式），RISET=1.18kΩ 时 ICC=1000mA。由此反推 ICC ≈ VISET / RISET ≈ 1.205V / RISET（待公式页确认 ❓）。豆包说的"1kΩ≈300mA"与此不符——设计前以官方公式为准。
      • 豆包把 CN3165 的 Riset 逻辑直接套到 IU5070E 上是错的，两者公式不同。

    3. 关键工程问题辨析（本人判断）¶

    3.1 ⚡ 豆包核心论证链条的根本性错误——已通过 datasheet 确认 ✅¶

    豆包的核心论证链条是：

    IU5070E 有光时芯片自身消耗 850µA（ICC） → 若整机负载 388µA，总耗 1.238mA → 太阳能 <1.2mA 就充不进、反而掉电 → 所以必须 MOS 切断 NFC 把负载压到 50µA 才能抵消。

    豆包混淆了三个完全不同的概念

    2026-08-05 二次更新：已获取 IU5070E 官方 datasheet（IU5070_ch_v1_1_r1.pdf）并通读全文 11 页，豆包的论证存在多重概念混淆：

    ① 850µA = IQ 静态电流（非充电态）¶

    符号 名称 条件 值
    IQ 芯片静态电流 VIN=5V, VEN 未使能（芯片空闲） 850 µA

    这是 VEN 不拉高时 VIN 端的漏电流，芯片什么都没干。

    ② ICC = 恒流充电输出电流（灌进电池的，不是芯片吃的！）¶

    符号 名称 公式 说明
    ICC 恒流充电电流 ICC = KISET / RISET = 400 AΩ / RISET 这是芯片向电池输出的充电电流，由外部电阻 RISET 设定！
    KISET 充电电流因子 400 AΩ 常数
    ITC 涓流充电电流 0.1 × ICC 预充电阶段
    IBF 终止电流 0.1×ICC / 0.033×ICC 充满判定的截止阈值

    例：RISET = 400Ω → ICC = 1A；RISET = 4kΩ → ICC = 100mA。这是你让芯片充多快的旋钮，不是芯片自己吃多少电。

    ③ 待机/漏电参数¶

    符号 条件 值
    IIN VEN 使能但待机（电池已满） 500 µA
    IBAT 无光纯电池泄漏 7~9 µA

    结论：豆包犯了什么错？¶

    1. 把 IQ（静态漏电 850µA） 当作"充电工作自耗"
    2. 把 ICC（充电输出电流 = 400/RISET） 当作"芯片自耗"——这完全是两个方向的电流！ICC 是流出芯片进电池的，不是芯片消耗的
    3. 基于这两个错误数字算出"1.2mA 临界点"→ 整个净充电账都是错的

    正确理解：IU5070E 在正常充电时的自身消耗（内部控制电路 + MPPT + DPPM 的 Operating Current），通读 datasheet 全文（11 页）确认未以任何符号给出该参数（只有 IQ/IIN/IBAT 三种静态/待机/漏电电流）。但可以确定它绝不是 850µA 也绝不是 ICC。

    我的判断（最终版）： 1. 豆包的"必须压到 50µA 才能抵消 850µA"结论不成立——因为 850µA 根本不是充电态参数。 2. NFC MOS 门控仍然值得做——但理由回归通用低功耗原则（Si522 休眠断电省几十 µA），而不是"抵消 850µA"。 3. 实测路径：datasheet 无工作态（充电中）电源电流参数，I_ic-self 在充电态的真实值需打样实测或咨询原厂（上海智浦欣）确认；弱光 KeyGo 场景可先用 IIN=500µA（使能待机） 作保守上限估算。

    3.2 IU5070E 全部电流参数一览¶

    把"芯片自己吃的电"和"芯片往电池灌的电"彻底分开：

    A. 芯片自身消耗（I_ic_self 的候选值）¶

    参数 工况 数值 含义
    IQ VEN 未使能（芯片空闲） 850 µA VIN 端静态漏电，充电时 VEN 必然使能，此值不适用
    IIN VEN 使能、电池已满（待机监测） 500 µA 待机态输入电流，弱光下最接近真实自耗的参考值
    IBAT 无 VIN / 夜间 7~9 µA 纯电池端泄漏，极小

    IU5070E datasheet 未给出工作态（充电中）电源电流参数，仅提供 IQ=850µA(空闲)/IIN=500µA(使能待机)/IBAT=7~9µA(漏电)。对弱光 KeyGo 场景，充电态芯片自耗可保守按 IIN=500µA 为基准、估计 0.5~1.5mA（线性充电器控制开销，随 ICC 略增）估算，或打样实测；绝不能用 850µA（那是未使能漏电流）。

    B. 充电输出参数（灌进电池的，不是芯片吃的）¶

    参数 公式/值 说明
    ICC（恒流充电电流） ICC = KISET / RISET = 400 AΩ / RISET 外部电阻设定。RISET=400Ω→1A, 4kΩ→100mA, 40kΩ→10mA
    ITC（涓流充电） 0.1 × ICC 预充电/低压阶段
    IBF（终止电流） 0.1×ICC (普通) / 0.033×ICC (USB100) 充满判定阈值
    VBAT(CV)（浮充电压） 4.16 / 4.2 / 4.24 V 三档可选

    KeyGo 场景的 RISET 选值建议

    SC-4747-9N 阴天 Isc 仅 500~900µA，充电电流 ICC 不应设太大（设大了也达不到，受限于光伏输出）。建议 RISET 设在 40~200 kΩ 范围，对应 ICC = 2~10 mA——晴天能充得动，阴天 DPPM 自动降功率。 - 若极端弱光优化：RISET 可更大（如 400 kΩ → ICC=1mA），与 MPPT 低至 1mA 的能力匹配。

    3.3 弱光下 DPPM 还生效吗？¶

    DPPM 是"输入电流环限幅"：先供负载、剩余充电池。官方资料确认 IU5070E 的 MPPT 有效充电低至 1mA ✅，即只要 I_pv ≥ 1mA 且电压 ≥ UVLO（3.6V），DPPM 环路稳定工作；低于 1mA 才失锁、启停。

    修正后的净充电判断（基于已确认参数 + 工作态自耗估算*）：

    工况 I_pv（SC-4747-9N） I_ic-self（估算*） I_load（KeyGo） I_net
    夏日暴晒 ~14 mA ~0.5–1.5 mA 35µA~4.4mA ✅ 正
    白天散射光 3~6 mA ~0.5–1.5 mA 35µA ✅ 正
    阴天弱光 0.5~0.9 mA ~0.5 mA（≈IIN 待机） 35µA ⚠️ 临界
    地下车库口 80~160 µA 500 µA（IIN，无光不充） 35µA ❌ 负

    * I_ic-self 为估算值：IU5070E datasheet 未给出工作态（充电中）电源电流，按 IIN=500µA（使能待机）为基准、弱光充电约 0.5~1.5mA 保守估。阴天区间仍是关键——但瓶颈是 I_pv 本身不够大，而非"850µA 芯片自耗"。这与豆包结论方向类似，物理原因完全不同。

    4. MPPT 是不是刚需？¶

    我的判断：MPPT 对 KeyGo 弱光场景是刚需，且已无"自耗过大"的顾虑

    • 非晶硅微型板 Voc 随光照剧烈浮动（车内 3.8~5.6V），无 MPPT 的线性充电 IC 把板子钳在 4.2V，弱光会浪费 20%~40% 功率，阴天甚至充不进——这点豆包说对了。
    • "850µA 自耗吃掉弱光电流"的担忧已不成立——850µA 是未使能态漏电，ICC 是输出电流，两者都不是充电工作态自耗。真实工作态自耗估计 0.5~2mA（见归档 datasheet PDF 确认 IVIN operating），对 mA 级光伏输出可接受。
    • 结论：MPPT 方向正确且必要，IU5070E 的 MPPT 低至 1mA 的能力与 SC-4747-9N 阴天 500~900µA 输出形成合理匹配。最终选型瓶颈在 I_pv（板子面积/效率） 而非芯片自耗。

    5. 推荐拓扑与避坑¶

    5.1 行业主流拓扑（SC 非晶硅板 + IU5070E）¶

    SC 非晶硅板 → IU5070E(VIN)
IU5070E(BAT) → DW06D 锂电保护 → 锂电池
锂电池 → SGM2034 常开 LDO → CH582M
CH582 GPIO → N-MOS → Si522(NFC，休眠断电)

    5.2 避坑清单¶

    硬件避坑

    1. NFC（Si522）必须 MOS 门控断电：通用低功耗好习惯，与 850µA 争议无关，独立成立。
    2. 非晶硅高压钳位：CN3165 最大耐压 ~6V，SC 板开路 5.6~6V 甚至 9V（10 串），必须串 5.6V 稳压管或 LDO 钳位；IU5070E 内建 8.6V OVP，可直连 9N/10 串板。
    3. 输入并联 10µF 低 ESR 钽电容：稳定弱光下波动的太阳能电压，防 MPPT 频繁重启。
    4. DW06D 锂电保护 IC：车载高温防过充过放，必加。
    5. SYSOFF 运输模式（IU5070E 支持）：夜间无光时拉低 SYSOFF 进零功耗，电池漏电降至 <0.5µA；需定时释放维持蓝牙广播。
